# tables/ — 需求表实例（模板 JSON，跨设备同步）

本目录存放 8 张已建好的表格实例，每张一个 `.pretty-table.json` 文件（应用「导出 JSON」功能产出，schemaVersion 1.2）。

## 另一台机器如何导入

1. 拉取本仓库，按 README 启动应用（`pnpm install` → `pnpm dev`，打开 `http://127.0.0.1:5173/`，本机被劫持回环时用 LAN IP）。
2. 模板库页「我的模板」区点 **「导入模板」**。
3. 选择本目录对应的 `.json` 文件（也可把文件内容粘贴进文本框），点「导入」。
4. 模板出现在「我的模板」，点「使用此模板」即可编辑、导出 HTML/PNG。

同一份文件重复导入是幂等的（同 id 覆盖，不会产生重复卡）。
