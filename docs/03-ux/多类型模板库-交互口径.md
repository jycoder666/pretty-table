# 多类型模板库 · 交互口径（草案）

> 项目：pretty-table · 文档类型：UX 模板域 · 状态：**草案 · UX-CAT-a 已锁 α；UX-CAT-b/c 随 FR-20 已定（2026-10-20）；具体底稿名单仍不锁**  
> 背景：用户纠偏——**不限保险行业**；支持多类型预设模板 + 模板内自定义轻改；**仍不开码**  
> 对齐：U-6A 表内槽位；自由画布**后置、非本期**；竞品摘录待 PM 落盘后对照锁定分类命名

---

## 0. 一句话

模板库是「多品类精美表底稿货架」：用户按**版式类型**选一张 → 进入编辑台改字/换主题/往虚线槽拖块 → 导出。  
行业样例（保险对比、价目、评测……）只是**预设内容**，不是产品边界。

---

## 1. 版式类型分类（交互草案）

按**结构骨架**分类，不按垂直行业。一张模板 = 一个骨架 + 一套默认文案/主题。

| 类型 ID | 名称（界面可显示） | 结构特征 | 典型用途样例（可换成任意行业） | 与旧稿关系 |
|---|---|---|---|---|
| **C-compare** | 多列对比 | 顶栏 N 列对象名 + 左栏对比项 + 表体交叉值 | 产品对比、套餐对比、竞品对比 | 原 T1 骨架 |
| **C-detail** | 单主体明细 | 左栏属性名 + 右栏值（可分组） | 保障/规格明细、参数表、价目说明 | 原 T2 骨架 |
| **C-matrix** | 宽表矩阵 | 多列档位 × 多行条目；首列锁定 | 档位评测、权限矩阵、价位带 | 原 T3 骨架 · **增强期上线（FR-20）** |
| **C-price** | 价目/清单 | 行项 + 数量/单价/小计列（轻编辑为主） | 报价单、材料清单 | **新增骨架 · 增强期上线（FR-20）**；小计不自动计算 |
| **C-timeline** | 分期/步骤表 | 阶段列或阶段行 + 说明槽 | 服务流程、缴费计划 | 新增骨架（草案）· **仍后置，未立项** |
| **C-custom** | 自定义底稿 | 仍用槽位制；行列由模板作者预置，用户不增删结构 | 「从空白感」的预置空表 | **后置/谨慎** · 易误解成 Excel |

**界面展示建议（P1）：**

- 顶部分类 Chip：`全部` | `多列对比` | `单主体明细` | `宽表矩阵` | …（有模板才显示 Chip）
- 卡片：缩略图 + **类型小标签** + 名称 + 一句用途（用途文案可行业化，类型标签保持通用）
- 筛选无结果：「没有这类模板，试试『全部』」+ 清空筛选

> **已定（2026-10-20）：** C-price、C-matrix 随增强期 FR-20 入库（Chip「价目清单」「宽表矩阵」，见 [增强期稿 §2](./增强期-粘贴填槽与导出选项.md#templates)）；C-timeline 仍后置。**仍待定：** C-custom 是否出现、Chip 文案是否更口语。

## 2. P1 选用与预览关系

| 步骤 | 交互 | 产出 |
|---|---|---|
| 浏览 | 网格卡片；可按类型 Chip 筛 | 无写操作 |
| 预览 | 悬停或点卡片 → 右侧/弹层大预览（只读渲染） | 不创建实例亦可 |
| 选用 | 「使用此模板」→ 克隆为可编辑实例进 P2 | `templateId` + 实例 ID |
| 换底稿 | P2 顶栏「换模板」回 P1；**提示将替换当前表内容**（可撤销若已有撤销；否则二次确认） | 新实例 |
| 另存复用 | P2「另存为模板」→ P1「我的模板」；系统预设只读不覆盖 | 见 `另存为模板-交互说明.md` |

**与槽位编辑关系：**

- P1 只决定**骨架与默认槽位布局**；不在库页拖块。
- 进入 P2 后：文案槽可改；区块槽遵守 U-6A；**不能**把库里的「另一张整表」当组件拖进当前表。

## 3. 多类型下的 U-1 口径调整

| 旧口径 | 新口径 |
|---|---|
| U-1 = 保险三套里选 2～3 | U-1 = 从**版式类型**里定首发 2～3 张**具体底稿**（可含保险样例文案，也可是中性占位） |
| 名单绑死行业名 | 名单写「类型 + 样例名」；样例可换皮 |

**结构级示例（不锁最终名单）：**

| 草案 ID | 类型 | 样例名（可改） | 说明 |
|---|---|---|---|
| T1 | C-compare | 「三列产品对比」 | 原保险对比骨架；占位可写「方案 A/B/C」 |
| T2 | C-detail | 「属性明细表」 | 原保障明细骨架 |
| T3 | C-matrix | 「档位矩阵」 | 原宽表评测骨架 |

首发组合建议仍可沿用 α=T1+T2，但表述改为：**先发「多列对比 + 单主体明细」两种骨架**，不表述为「保险两套」。

槽位细节仍见 `U-1-模板槽位清单-草案.md`（已去行业绑死表述）。

## 4. 自由画布后置时：编辑台如何避免暗示可乱放

本期**不写**自由画布为已定能力。界面与文案必须持续传达「表内槽位」：

| 位置 | 要做 | 不要做 |
|---|---|---|
| 组件库顶说明 | 「仅可放入表内虚线槽，不能自由摆放」 | 「拖到画布任意位置」「自由添加卡片」 |
| 预览区光标/高亮 | 仅槽位高亮可放；表外无落点反馈 | 整页可放置高亮、吸附到像素网格 |
| 空槽提示 | 「放到虚线框内」 | 「随便找个空位放下」 |
| 禁操作 | 无「画布模式」开关；无「表外图层」面板 | 灰显但可点的「画布」入口（易期待） |
| 帮助/空态 | 「这是模板表，结构已定好」 | 「从零搭建页面」 |

后置若开画布：须另开 ADR + 独立模式入口（明确切换），**不得** silently 扩大当前拖拽落点。对照短述见群内交互回复；详细工时归架构。
