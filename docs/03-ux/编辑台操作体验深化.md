## 0. 体验原则（手感 · Fill）

| # | 原则 | 落地含义 |
|---|---|---|
| 1 | 模板内饱满编辑（Fill） | 能选区合并/拆分、改字对齐强调、拖区块微调；一切仍落在「槽位 / 允许区」；越界只提示、不偷偷成功 |
| 2 | 所见即所得 | 右侧改文案/主题/合并/对齐后，中间预览 ≤200ms 级感知更新（文档约定，非性能 SLA） |
| 3 | 失败可读 | 拖失败、合并失败、导出失败、渲染失败都有短句 + 可重试；禁止静默 |
| 4 | 动效克制 | 槽位高亮、合并闪边、落块淡入、toast；禁止弹跳/粒子/长动画/整页 loading |
| 5 | 禁操作明示 | 点到「不允许」时用一句白话说明边界，不弹技术错误码；不暗示 Mid/Heavy/画布可做 |

**与「只换肤」的差异**：主路径仍是模板，但编辑台要能 **选中 → 允许区合并/拆分 → 改字与强调 → 拖区块 → 撤销**，导出所见即所得。

### 1.1 P1 模板库

| 状态 | 界面表现 | 文案（建议） | 操作 |
|---|---|---|---|

## 2. 关键路径文案（槽位填空 + Fill 结构/单元格）

### 2.1 空槽占位

| 槽类型 | 占位文案示例 |
|---|---|
| 产品名 / 方案名 | 「填写产品名称」 |
| 条款短句 | 「填写保障说明」 |
| 数值（保费等） | 「0」或「填写金额」（模板二选一，同一模板内统一） |
| 分组标题（拖入后） | 「填写分组标题」 |
| 强调注脚 | 「填写备注或推荐语」 |
| 左栏标签 | 「推荐」等短标签默认值可预填，仍可改 |
| 通用空槽（C1） | 「填写…」 |

规则：占位用**中性灰**；用户聚焦后清空或全选便于覆盖；导出时**不得**把占位原文当正式内容导出——空槽导出为空字符串或模板规定的默认（**待确认 U-导出空槽**：假设导出为空，不输出占位句）。

### 2.3 选 · 合并 · 拆分 · 对齐 · 强调（手感全状态）

#### 2.3.1 点选 / 多选（TH-S1 / S2）

| 态 | 表现 | 文案 |
|---|---|---|
| 未选 | 右栏空引导；结构与强调类控件禁用 | 「点选单元格或表内区块后，在此编辑」 |
| 单选成功 | 选中描边；右栏切对象 | — |

| 多选进行中 | 选区半透明高亮 | — |

| 多选合法 | 选区高亮；「合并」可点 | — |

#### 2.3.2 有限合并（TH-R1）

| 态 | 表现 | 文案 |
|---|---|---|
| 入口 | 合法选区后顶栏/属性「合并」；允许区悬停「可合并」弱标 | — |

| 禁暗示 | **无** Excel 拖角；入口仅属性/工具条 | 误触拖角：「此处不能像 Excel 那样拖角合并」 |

| 态 | 表现 | 文案 |
|---|---|---|
| 入口 | 选中已合并格 →「拆分」 | — |
| 失败·locked 预设 | 「拆分」禁用或 toast | 「这是模板固定合并，不能拆」 |
| 成功（用户自并） | 拆回栅格 | toast「已拆分」 |

#### 2.3.4 对齐 / 强调（TH-C2 / C3）

| 态 | 表现 | 文案 |
|---|---|---|
| 无选中 | 对齐三钮与强调控件禁用 | 跟空引导 |
| 对齐成功 | 预览即时；toast 可省 | — |
| 强调成功 | 底色/加粗可见；与主题 token 一致 | — |
| 选中禁止强调区（Q-004） | 表头行、左栏项名、非槽只读格、区块内：红字/加粗/底色三钮置灰 | 悬停：「此处由模板固定，不能强调」 |
| 强调写入另存 | 实例态；另存模板时可一并写入（对齐 SAVE） | — |

### 2.4 空选态汇总

| 条件 | 右栏 | 顶栏相关 |
|---|---|---|
| 未选中 | 「点选单元格或表内区块后，在此编辑」 | 合并/拆分禁用 |
| 多选未合法 | 弱提示选相邻允许格 | 「合并」禁用 |
| 选中 locked 合并格 | 可编辑文案（若允许）；拆分禁用 | 拆分禁用或点后 toast |

### 2.5 成功微反馈（非导出 · TH-F3）

| 动作 | 反馈 |
|---|---|

## 3. 槽位拖拽反馈与约束（U-6A · TH-B1/B2）

对齐版式清单 §5；此处补**手感时序与文案**。

### 3.1 拖拽时序

| 阶段 | 表现 |
|---|---|
| 抓起 | 组件库项幽灵图跟随指针；原位可留虚影（加厚：预览幽灵块） |
| 经过可放槽 | 槽位**虚线框 + 主题浅底**高亮；光标「可放置」 |
| 经过不可放 | 无高亮；光标「禁止」或默认；可红色脉动一次（松手前） |
| 命中松手 | 区块落成 + ≤200ms 淡入；写入实例数据；可立刻在属性改文案 / B2 微调 |
| 未命中松手 | 幽灵回弹组件库；toast 短提示（见下） |
| 槽位已占用 | **与需求对齐：替换** → 清旧落入新；toast「已替换原区块」（原 UX-T3「禁止叠放」作废） |

### 3.2 拖拽相关文案

| 场景 | 文案 |
|---|---|
| 未命中槽位 | 「请放到表内虚线槽位」 |
| 拖到表外 / 侧栏 | 同上（不区分技术落点） |
| 拖到错误类型槽（如注脚拖到行间色条槽） | 「这里不能放这个区块」 |
| 试图当画布乱放 | 无画布入口；若误操作仅用上列提示 |
| 删除已落成区块 | 属性或区块悬停「移除」→ 二次确认：「移除后可从左侧重新拖入」· 按钮「移除 / 取消」 |

### 3.2.1 点击添加（辅助）

与拖拽等价：单击组件库项进入「待放置」→ 再点高亮槽位落成；Esc 取消。详见页面流 G-UX-05。

### 3.2.2 区块样式微调（TH-B2 · 本期 IN）

| 项 | 约定 |
|---|---|
| 入口 | 选中已落区块 → 属性：色条深浅（3 档）、注脚字号（2 档） |
| 成功 | 预览即时 |
| 边界 | **仍无**自由定位、无表外摆放、无新增区块种类（B3 后置） |

### 3.3 组件库侧状态

| 状态 | 表现 |
|---|---|
| 默认可拖 | 4 类均展示（实现可先启用 2 类：色条+分组标题）；未启用类：**灰显 + tooltip「即将支持」**，不可拖 |
| 拖拽中 | 非目标区降低存在感（可选） |
| 说明 | 库顶一行小字：「仅可放入表内槽位，不能自由摆放」 |

## 4. 禁操作可读反馈（Fill 边界 · 不重开 OUT）

用户点到「本期不做」能力时，用白话挡回去（无入口更优；若误触残留控件则提示）。与加厚草案 TH-F2 / R5 / X1 同一口径。

| 用户意图 | 反馈文案 |
|---|---|
| 增删行列 | 「当前模板不支持增删行列」 |
| 任意合并非允许区 | 「此处不能合并，请使用模板已开放的合并区」 |
| Excel 拖角任意合并 | 「此处不能像 Excel 那样拖角合并」 |
| 拆模板 locked 合并 | 「这是模板固定合并，不能拆」 |
| 公式 / 填充柄 / 筛排 / 冻结 | 无入口（Heavy **本期不做**） |
| 列宽拖拽 / 有限增行 | 无入口（Mid **本期不做**；增行须另议重开 OUT） |
| 自由画布 / 表外卡片 | **无入口、无开关、无灰显可点**；组件库顶已说明「仅可放入表内虚线槽」 |
| Excel 导出 | 导出区不出现；若从别处提及 → 「本期请用 HTML 或 PNG」 |
| 把整表当组件拖入 | 不支持；换底稿走 P1「换模板」 |

### 4.1 防暗示乱放（画布后置 · TH-X1）

| 位置 | 必须 | 禁止出现的文案/控件 |
|---|---|---|
| 组件库顶 | 「仅可放入表内虚线槽，不能自由摆放」 | 「拖到画布」「自由放置」「添加卡片到表外」 |
| 预览落点 | 仅槽位高亮 | 整页可放高亮、像素吸附网格 |
| 帮助/空态 | 「这是模板表，结构已定好；允许区内可合并改字」 | 「从零搭建页面」「像 Excel 一样随便改」 |
| 设置 | 无「画布模式」；无「Excel 模式」 | 即然后置也不在本期露出入口 |

后置若开画布：须独立模式切换 + 新 ADR，不得扩大当前拖拽落点。

### 4.2 Mid / Heavy 后置说明（本期不做）

| 包 | 含什么 | 本期文档处置 |
|---|---|---|
| Mid | 列宽拖拽、可选封顶增行等 | **无入口、无交互细则**；增行须重开 OUT 另议 |
| Heavy | 筛选/排序/冻结/填充柄/公式等 | **明确不做**；仅记下后置，另立项才议 |
| Slim / Stretch | 未选包 | 不采用；以已锁 Fill 为准 |

## 4.5 另存为模板（P2）

| 步骤 | 界面 | 文案 |
|---|---|---|
| 点入口 | 顶栏次按钮「另存为模板」 | — |

## 5. 导出前后反馈（补强）

### 5.1 导出前检查（壳层，无代码约束仅体验）

| 检查 | 行为 |
|---|---|
| 预览仍在加载/错误 | 禁用复制与 PNG；说明见 §1.3 |
| 存在大量空槽 | **不阻断**；可选弱提示「还有未填内容，确定导出？」· **待确认**是否要二次确认（假设：**不二次确认**，免打断） |

### 5.2 导出后

| 路径 | 成功后引导（一句） |
|---|---|
| HTML | 「可粘贴到介绍页或邮件」 |
| PNG | 「可用于方案书或发群」 |

不自动打开新站点；不强制分享。

### 5.3 与预览一致性预期

文案侧约定：用户应理解「导出 = 当前预览所见」（含合并/强调/区块态）。若未来有「仅导出选区」——**本期不做**，界面不出现选区导出。

## 6. 焦点、键盘与可达性（轻量）

| 项 | 本期约定 |
|---|---|
| 槽位点选 | 鼠标点选为主；多选桌面用拖选 / Shift+点；Tab 在属性表单内可用 |
| Esc | 取消拖拽中 / 取消待放置 / 关闭导出抽屉（若有） |
| 撤销 | Ctrl+Z / 顶栏撤销（TH-F1）；覆盖文案/主题/合并/拆分/对齐/强调/区块 |
| 对比度 | 占位灰字、禁用态须可辨；强调红字避免纯红无加粗时过淡 |
