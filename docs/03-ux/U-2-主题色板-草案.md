# U-2 · 主题色板

> 项目：pretty-table · UX · 状态：**已锁（pack-A3）**  
> 对齐：需求 U-2；版式清单「多主题换色 / 禁止过炫渐变」；设计方案 §3.2 token 最小集  
> 约束：**无渐变主题**；导出 HTML/PNG 仍可读；少 AI 味（禁紫霓虹、大面积玻璃拟态、彩虹强调）  
> 配套：U-1 样例文案方向 **A 通用商务**（产品回写）

---

## 0. 设计原则

1. **纸本感**：表像印在纸上——底色偏纸白/米白，不是深色仪表盘。  
2. **一主一辅**：每套只有一个主色管表头/分区；强调色克制，只打关键格。  
3. **打印友好**：主色饱和适中，灰阶斑马与边框在黑白打印仍能分出层级。  
4. **换皮即换 token**：`themeId` 切换后 `primary / zebra / emphasis / border / paper / headerText` 整组替换；无逐格手调色盘（本期）。

## 1. 三套方向（**已锁首发**）

### T-A · 蓝白台账（**默认 · 已锁**）

| 意象 | 银行对账单 / 产品参数对照——冷静、通用、不绑行业 |
|---|---|
| 纸色 `paper` | `#F7F9FC` |
| 表头/分区 `primary` | `#2F5B9A` |
| 表头字 `headerText` | `#FFFFFF` |
| 斑马 `zebra` | `#EEF2F7`（可关） |
| 强调 `emphasis` | `#C0392B`（红字或浅红底 `#FDECEA`） |
| 边框 `border` | `#C5D0DE` |
| 左栏标签 `tag` | `#E8EEF6` 底 + `#2F5B9A` 字 |

**气质**：干净、默认安全；适合对比表与明细表首屏。  
**禁止**：把蓝做成荧光科技蓝或蓝紫渐变。

---

### T-B · 墨青簿册

| 意象 | 会计簿 / 内部汇报册——偏编辑感，少「SaaS 蓝」 |
|---|---|
| 纸色 `paper` | `#F4F6F3` |
| 表头/分区 `primary` | `#2F4F45` |
| 表头字 `headerText` | `#F5F7F4` |
| 斑马 `zebra` | `#E8EDE8` |
| 强调 `emphasis` | `#A65B2A`（赭石，非鲜橙） |
| 边框 `border` | `#B7C2B8` |
| 左栏标签 `tag` | `#DCE5DF` 底 + `#2F4F45` 字 |

**气质**：沉稳、偏线下材料；对比蓝白能拉开「换皮」体感。  
**禁止**：墨绿霓虹、大面积深绿底白字整表（易糊）。

---

### T-C · 暖灰金（克制）

| 意象 | 画册目录 / 价目册封面——轻贵气，不土豪金 |
|---|---|
| 纸色 `paper` | `#FAF7F2` |
| 表头/分区 `primary` | `#4A463F` |
| 表头字 `headerText` | `#FAF7F2` |
| 斑马 `zebra` | `#F0EBE3` |
| 强调 `emphasis` | `#8A6A2F`（哑光金棕；底可选 `#F5EDD8`） |
| 边框 `border` | `#D4CBBC` |
| 左栏标签 `tag` | `#EDE6DA` 底 + `#4A463F` 字 |

**气质**：偏品牌册；强调用金棕而非亮黄。  
**禁止**：大面积金属渐变、金色描边闪烁。

## 3. 编辑台交互（主题切换）

| 项 | 口径 |
|---|---|
| 入口 | 右栏「主题」区：**3** 个色块按钮（主色条 + 名称：蓝白 / 墨青 / 暖灰金），非下拉 |
| 反馈 | 中栏预览轻淡入 ≤300ms；无整页 loading；无「保存成功」 |
| 默认 | 新实例 = **T-A 蓝白**；另存模板保留当时 `themeId` |
| 斑马 | 主题内可开/关；关则 `zebra` 不用，行底统一 `paper` |
| 失败 | `themeId` 缺失 → 回退 T-A + toast「主题不存在，已用默认」 |

文案示例：按钮旁一句「一键换表头、分区与强调色」。

## 4.1 前端 token 落点（遵守，不开码说明）

| `themeId` | 展示名 | 备注 |
|---|---|---|
| `T-A` | 蓝白台账 | **默认**；缺省 / 非法 id 回退至此（对齐开发约定） |
| `T-B` | 墨青簿册 | 必出荷 |
| `T-C` | 暖灰金 | 必出荷 |

每套必须提供整组：`paper` · `primary` · `headerText` · `zebra` · `emphasis` · `border` · `tag`（hex 见 §1）。  
壳只暴露三按钮切换 `themeId`；**禁止** UI 减少为两套；**禁止**自定义色盘入口。  
核：`applyTheme(themeId)` → 映射为 VTable theme / 导出内联样式。  
说明：曾草案用过 `blue-white` 等别名，**以 `T-A`/`T-B`/`T-C` 为准**，与架构开发约定一致。
