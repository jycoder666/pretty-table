# 表格版式能力清单

> 项目：pretty-table · 文档类型：UX 能力边界 · 状态：草案（U-6 **已锁 A**）

## 1. 背景与已锁方向

| 项 | 结论 |
|---|---|
| 产品 | pretty-table（网页精美表格工具） |
| 主方向 | **B 模板首发 + A 轻编辑底层** |
| 交付形态 | **在线工具为主，预留嵌入**（壳 + 渲染核分层） |
| 主核（假设） | 倾向 **VTable**（MIT）；正式 ADR 待架构师落盘后确认 |
| **U-6 拖拽** | **已锁 A：表内槽位拖入**（非整页自由画布） |
| 本期不做 | 重编辑 / FortuneSheet、公式、协作、完整电子表、AG Grid/Tabulator 作主核；自由画布拼表 |

本文只锁**版式能力与交互边界**，不写实现与选型细节。

| 能力 | 验收要点 | 本期 |
|---|---|---|
| 多级表头 | 支持 2～3 级表头；层级视觉可区分 | 做 |
| 左栏 / 顶栏色块 | 左侧标签列、顶部栏目可用主题色块 | 做 |

| 分组标题行 | 可插入跨列分组标题行 | 做 |
| 宽表首列钉住 | 列数多时首列固定，其余横向滚动 | 做 |

## 3. 视觉能力（可验收）

| 能力 | 验收要点 | 本期 |
|---|---|---|
| 多主题换色 | **3 套**（pack-A3：蓝白默认/墨青/暖灰金）可一键切换；表头/分区/强调色随主题变；**禁止砍成 2 套** | 做 |
| 斑马纹 | 可开/关；与主题色协调 | 做 |
| 外框 | 清晰表格外框；不过于厚重 | 做 |
| 强调 | 支持红字 / 加粗 / 底色强调（可组合） | 做 |
| 对齐规则 | **数字右对齐** · **文案左对齐** · **状态类居中** | 做 |

### 禁止风格

- 过炫渐变、装饰插画抢视线
- 动效仅允许轻量（如主题切换淡入）；禁止花哨动画

## 4. 轻编辑边界

### 做（本期）

- 改单元格文案（槽位填空）
- 换主题 / 斑马纹 / 强调样式
- 有限合并区微调（在模板允许的合并栅格内）
- 选用整表模板；**从表内组件库拖入区块到模板槽位**（U-6A）

### 不做（本期）

- 随意增删行列
- 公式、协作、完整电子表体验
- 自由画布拼表 / 表外图文混排
- 单元格级自由拖合并、拖排序当 Excel

## 5. 拖拽对象清单（U-6A · 已锁）

### 5.1 定档声明

| 项 | 结论 |
|---|---|
| 定档 | **U-6 = A · 表内槽位拖入** |
| 含义 | 用户从编辑台左侧组件库拖入**表内区块**，落点只能是模板预留的**槽位 / 区块位**；写入模板 JSON，由渲染核画出 |
| 不是 | 非整页自由画布；不是低代码页面搭建；不是 Excel 式单元格拖拽 |
| 与主方向关系 | 仍属 **B 模板 + A 轻编辑**；组件是槽位扩展，不另起编辑器 |

### 5.2 可拖对象（≥4 类表内区块）

每条：用途 / 可拖入位置 / 与模板槽位关系。

#### （1）分区色条

| 维 | 说明 |
|---|---|
| 用途 | 横向色带，把表体分成上下内容区（如「基础保障 / 增值服务」） |
| 可拖入位置 | 模板标注的**行间区块槽**（两行内容区之间）；不可拖到表外、表头单元格内随意叠放 |
| 与模板槽位 | 落成后成为模板 JSON 中的 `block: sectionBar`；占一行（或模板规定的行高），色随主题 token |

#### （2）分组标题行

| 维 | 说明 |
|---|---|
| 用途 | 跨列分组标题，标识下一组对比项（如「身故责任」「医疗责任」） |
| 可拖入位置 | 模板的**分组标题槽 / 行区块位**；通常跨满数据列宽 |
| 与模板槽位 | 落成 `block: groupHeader`；文案可再在属性面板改；不得拆成自由坐标浮层 |

#### （3）强调注脚

| 维 | 说明 |
|---|---|
| 用途 | 表底或分区底的说明/免责/推荐语一行（可红字或底色强调） |
| 可拖入位置 | 模板的**注脚槽**（表末或分区末预设位） |
| 与模板槽位 | 落成 `block: emphFooter`；属表内一行，非表外脚注卡片 |

#### （4）左栏标签块

| 维 | 说明 |
|---|---|
| 用途 | 左侧标签列中的色块标签（如「推荐」「必选」「可选」） |
| 可拖入位置 | 模板**左栏标签槽**（指定行的左侧标签格） |
| 与模板槽位 | 落成 `block: leftTag`；绑定到已有行槽，不新建自由列 |

> 整表模板从模板库换底稿，**不算**本清单的「拖拽对象」；换模板走 P1，不走组件 DnD。

#### 5.2.1 首发启用范围（Q-003 定稿）

| 区块类 | 首发 | 组件库表现 |
|---|---|---|
| 分区色条 | **启用**，可拖、可点击添加 | 正常 |
| 分组标题行 | **启用**，可拖、可点击添加 | 正常 |
| 强调注脚 | **二期**，首发不可拖 | 列表里可见但置灰，悬停提示「下一期开放」 |
| 左栏标签块 | **二期**，首发不可拖 | 同上 |

- **各模板的区块槽位置**：T1 见 U-1 §1.4（行间分区界放色条；表体部分行前放分组标题行，预置 1～2 个空位）；T2 见 U-1 §2.4（大类分界槽，色条和分组标题行都能放）。表末注脚槽、左栏标签槽首发不显示虚线。
- **色条与分组标题行互斥**：同一个分隔槽只放一个区块。槽里已有一种，再拖入另一种就替换掉旧的，提示「已替换原区块」（同 FR-09 同槽替换）。
- **验收影响**：「注脚字号 2 档」放到二期验收；首发的区块样式微调只验色条深浅。

### 5.3 禁止项（本期）

| 禁止 | 理由 |
|---|---|
| 自由画布 / 任意 xy 坐标摆放 | 改主方向，等于 D 档 |
| 表外卡片、图、图文混排块 | OUT-8；属画布层，后置 |
| 单元格级当 Excel：拖合并、拖排序、拖填充 | OUT-9；破坏轻编辑边界 |
| 随意增删行列 | OUT-1；模板结构锁死 |
| 多表拼装、跨表拖区块 | 超出单表模板 |
| 把组件拖到预览区空白「任意落点」 | 落点必须命中槽位高亮；未命中则回弹/提示 |

### 5.4 禁止照搬

- **过炫动效**：拖入仅允许轻量落位反馈（高亮槽、短淡入）；禁止弹跳、粒子、长动画
- **低代码页面搭建**：禁止把 DnD 做成「拖按钮/表单/侧栏导航」的页面搭建器；组件库**仅表内版式区块**
- **竞品全家桶照抄**：不做完整电子表工具栏、不做无限组件市场

### 5.5 对照 FR-08 的验收要点

| # | 验收点 | 通过标准 |
|---|---|---|
| A1 | 组件库可见 | 编辑台左侧列出 ≥2 类可拖区块（本期建议 4 类均可见，至少上线 2 类） |
| A2 | 拖入落点 | 拖到模板槽位时槽位高亮；松手后区块出现在表内对应位 |
| A3 | 仍是一张表 | 拖入后 DOM/导出仍是单一表格结构，无表外绝对定位浮层 |
| A4 | 可填字 | 拖入的分组标题/注脚/标签等，可在右侧属性或点选后改文案 |
| A5 | 无自由画布入口 | 界面无「画布」「自由放置」「添加卡片到表外」等入口 |
| A6 | 无 Excel 拖姿态 | 无拖角合并、无行/列拖排序把手（有限合并仅走属性面板） |
| A7 | 写入模板数据 | 落成结果反映在模板实例数据中，刷新预览仍在（不单靠临时 DOM） |
| A8 | 导出一致 | 含拖入区块的表，复制 HTML / 导出 PNG 与预览结构一致 |
