# U-1 首批模板槽位清单（草案）

> 项目：pretty-table · 文档类型：UX 模板槽位 · 状态：**草案 · 首发类型已锁 α；具体底稿文案名仍可调**  
> 用途：供 PM/用户讨论 U-1；确认前**不写入**需求定稿句  
> 对齐：`多类型模板库-交互口径.md`（**不限保险**）；U-6A 表内槽位；版式清单 §5  
> 说明：T1/T2/T3 = **版式骨架**（C-compare / C-detail / C-matrix）；文案默认中性占位，行业样例可替换

---

## 0. 怎么读这份草案

每个模板给出：

1. **结构草图**（行/列角色，非实现 JSON）
2. **文案槽**（填空）
3. **区块槽**（可拖入哪些 U-6A 对象）
4. **轻编辑允许区**（主题/强调/有限合并）
5. **验收一眼看**（陌生人能判「像不像这张表」）

命名：`T1`/`T2`/`T3` 是骨架编号，不是行业包。最终首发可只取 2 张。  
库页分类/预览/选用见 `多类型模板库-交互口径.md`。

## 1. T1 · 多列对比表（C-compare）

### 1.1 用途

多对象并排比属性、条款、价格等。默认占位「方案 A/B/C」；可换成任意行业填充（含原「保险产品对比」样例）。

### 1.2 结构草图

```
        | 槽·对象A名 | 槽·对象B名 | 槽·对象C名 |
左栏标签|    …单元格槽…（可强调）
── 区块槽·分区色条（可选拖入）──
分组行  | 跨列分组标题（可选拖入或模板预置）
对比行×N| 左栏项名槽 | 值槽 | 值槽 | 值槽
── 区块槽·强调注脚（表末，可选）──
```

| 区 | 说明 |
|---|---|
| 顶栏 | 1 行对象名（3 列数据；模板可配置 2～4 列，**首发固定 3 列**假设） |
| 左栏 | 对比项名称列；部分行带「左栏标签槽」 |
| 表体 | 预置 N 行对比（建议 6～10）；**不可增删行** |
| 多级头 | 可选第 0 行「分组档」合并（见有限合并） |

### 1.3 文案槽清单

| 槽 ID（逻辑名） | 位置 | 占位 | 类型 |
|---|---|---|---|
| `obj.name.{a,b,c}` | 顶栏三列 | 填写名称 | 短文本 |
| `row.{i}.label` | 左栏项名 | 填写对比项 | 短文本 |
| `row.{i}.val.{a,b,c}` | 表体 | 填写说明或数值 | 文本/数值 |
| `group.title.{g}` | 分组标题行 | 填写分组标题 | 短文本 |
| `footer.note` | 注脚 | 填写备注 | 一句话 |
| `leftTag.{r}` | 左栏标签格 | 推荐 / 亮点… | 短标签 |

### 1.4 区块槽（可拖）

| 槽位 | 允许拖入 | 默认 |
|---|---|---|
| 行间 · 分区界 | 分区色条 | 模板可预置 1 条，仍可移除后重拖 |
| 表体部分行前 | 分组标题行 | 建议预置 1～2 个空位 |
| 表末 | 强调注脚 | 空；可选拖入 |
| 指定左栏行 | 左栏标签块 | 1～2 个预留位 |

禁止：往顶栏名称格拖色条；往任意单元格拖「自由卡片」。

### 1.5 轻编辑允许

| 能力 | T1 |
|---|---|
| 换主题 / 斑马纹 | ✓ |
| 单元格强调（红字/加粗/底色） | ✓ 表体值槽、对象名；表头行、左栏项名、非槽只读格、区块内**不可强调**（Q-004） |
| 有限合并 | 仅预置「顶栏分组」合并区可微调跨度；**禁止**拆掉左栏整列合并；逐格见 §7.1 |

### 1.6 一眼验收

- 三列名称可改且预览同步  
- 至少一处多级头或左栏色块标签  
- 拖入分区色条后导出 HTML 仍是单表

## 2. T2 · 单主体明细表（C-detail）

### 2.1 用途

单对象属性/条款分层说明：分区标题 + 明细行 + 底备注脚。样例可填「产品规格」「保障明细」「服务说明」等。

### 2.2 结构草图

```
表头：主体名槽 | 版本/计划槽
── 分组标题 / 分区色条（大类）──
明细行：项名槽 | 说明/数值槽 | 备注槽
…
── 强调注脚──
```

| 区 | 说明 |
|---|---|
| 表头 | 1～2 个文案槽 |
| 表体 | 预置分组 + 明细行；**不可自由增删行**（换模板或后置能力另议） |
| 注脚 | 可选区块槽 |

### 2.3 文案槽清单

| 槽 ID | 位置 | 占位 |
|---|---|---|
| `subject.name` | 表头 | 填写名称 |
| `subject.plan` | 表头 | 填写版本/计划 |
| `row.{i}.label` | 项名 | 填写项名 |
| `row.{i}.value` | 说明列 | 填写内容 |
| `row.{i}.note` | 备注列 | 选填 |
| `group.title.{g}` | 分组 | 填写大类名 |
| `footer.note` | 注脚 | 填写须知一句 |

### 2.4 区块槽

| 槽位 | 允许 | 默认 |
|---|---|---|
| 大类分界 | 分区色条 / 分组标题（互斥假设见 U-1-c） | 预置 1～2 |
| 表末 | 强调注脚 | 空 |
| 左栏标签 | 少用 | 0～1 |

### 2.5 轻编辑允许

换主题、值槽强调、分组标题文案；合并以模板预置 locked 为准，逐格见 §7.2。

### 2.6 一眼验收

- 改主体名与若干明细行，预览同步  
- 分区界清晰；导出仍为一张表

## 3. T3 · 宽表矩阵（C-matrix）

### 3.1 用途

多档位 × 多条目交叉（权限、价位带、评测档等）。宽表横滑；首列项名锁定。

### 3.2 结构草图

```
        | 档A | 档B | 档C | …
项名列钉|  交叉值槽…
── 分组标题（条目族）──
```

| 区 | 说明 |
|---|---|
| 顶栏 | 档位名槽（首发建议 3～5 列） |
| 首列 | 条目名；滚动时钉住 |
| 表体 | 交叉值；可强调 |

### 3.3 文案槽 / 区块槽（摘要）

- 档列头、条目名、交叉值、分组标题、可选注脚  
- 区块：分组标题为主；色条次之；左栏标签可选  

### 3.4 一眼验收

- 档列头可改；交叉含义可读  
- 宽表可横滑且项名列固定  
- 拖入分组标题后族间分隔清楚

## 4. 首发组合建议（仍为草案）

| 方案 | 组合 | 理由 |
|---|---|---|
| **推荐 α** | T1 + T2 | 覆盖「多列对比」+「单主体明细」两骨架；差异够大 |
| 备选 β | T1 + T3 | 两套都偏「多列」，差异略小 |
| 备选 γ | T1 + T2 + T3 | 最全；首发成本最高 |

**已锁 α**（2026-10-20）：两种版式类型 C-compare + C-detail（T1+T2）。具体样例文案/底稿名仍可调，不锁行业。  
更多类型（价目 C-price、分期 C-timeline）见交互口径，**不锁进本清单名单**。

## 7. 首发格位表（Q-002 · T1 / T2）

> 供开发建模板、PM 验收对照。坐标：`R` 行、`C` 列，从 0 起；`G1/G2` 是行间分隔槽（不占格位行号，拖入区块后在该处多出一行区块行）。

### 7.0 通用规则

| 项 | 规则 |
|---|---|
| 可写格 | 用户可改文字；可强调（红字/加粗/底色），除非下表注明不可强调 |
| 只读格 | 模板固定文字，不能改、不能强调、不能合并；选中后右栏提示「此处由模板固定」 |
| locked 合并 | 模板预置的合并，不能拆、不能改跨度；选中后「拆分」按钮置灰 |
| 允许合并区 | 只有区内相邻格能合并/拆分；区外选区「合并」按钮置灰 |
| 合并后文字（Q-002） | 保留左上格文字，其余格内容清除；合并前不弹确认，可撤销一步（FR-11）找回 |
| 拆分后文字 | 文字留在左上格，其余格为空 |
| 分隔槽 | 色条与分组标题互斥，同槽再拖入替换（版式清单 §5.2.1）；分组标题行只能改标题文字 |
| 首列钉 | 预览横向滚动时 C0 固定在左侧（T1/T2 首发宽度一般不横滑，窄屏 ≤375px 时生效） |

### 7.1 T1 多列对比（4 列 × 10 行 + 2 个分隔槽）

| 行 | C0 | C1 | C2 | C3 | 说明 |
|---|---|---|---|---|---|
| R0 | 「项目」只读，**locked 合并 R0–R1** | `band.1` 默认「分组档 1」 | （默认与 C1 合并） | `band.2` 默认「分组档 2」 | 多级表头第 1 层；**允许合并区 = R0:C1–C3 横向**，默认 C1–C2 合并；表头行不可强调 |
| R1 | （合并内） | `obj.name.a` | `obj.name.b` | `obj.name.c` | 多级表头第 2 层；对象名可改、可强调 |
| G1 | 分隔槽，预置分组标题「分组一」 | | | | 可删、可换色条 |
| R2–R5 | `row.{i}.label` | `row.{i}.val.a` | `.val.b` | `.val.c` | 4 条对比行；C0 不可强调 |
| G2 | 分隔槽，默认空 | | | | 可拖入色条或分组标题 |
| R6–R9 | `row.{i}.label` | `row.{i}.val.a` | `.val.b` | `.val.c` | 4 条对比行 |

- 表体（R2–R9 × C1–C3）**不设允许合并区**：对比表值格合并会让对象对不上。
- 首列钉：C0。
- 二期预留：左栏标签位 R2、R6（首发置灰）；表末注脚槽（首发置灰）。
- 增强期：可设推荐列 = C1～C3 任选一列（FR-23）；值格 kind 默认文本，模板可把 R2–R5 声明为符号槽（FR-21）。

### 7.2 T2 单主体明细（3 列 × 10 行 + 2 个分隔槽）

| 行 | C0 | C1 | C2 | 说明 |
|---|---|---|---|---|
| R0 | `subject.name`，**locked 合并 C0–C1** | （合并内） | `subject.plan` | 表头第 1 层；可改文字，不可强调 |
| R1 | 「项目」只读 | 「说明」只读 | 「备注」只读 | 表头第 2 层（列头） |
| G1 | 分隔槽，预置分组标题「基本信息」 | | | |
| R2–R5 | `row.{i}.label` | `row.{i}.value` | `row.{i}.note` | C0 不可强调 |
| G2 | 分隔槽，预置分区色条 | | | 可换分组标题 |
| R6–R9 | `row.{i}.label` | `row.{i}.value` | `row.{i}.note` | |

- **允许合并区 = 每条明细行的 C1–C2 横向**（说明写长时跨到备注列）；不能跨行合并。
- 首列钉：C0。
- 二期预留：表末注脚槽（首发置灰）。

## 8. 增强期槽位声明表（Q-012 · 价目 / 矩阵，FR-20～23）

> 字段：`kind` 文本 / 数字 / 百分比 / 货币 / 符号；`format` 显示格式；`fractionDigits` 小数位（未写 = 按增强期稿 §4.3 默认）；`unit` 后缀单位；`locked` 是否模板固定；`recommendableCols` 可否设推荐列。粘贴与解析规则见 [增强期稿 §1.4、§4.3](./增强期-粘贴填槽与导出选项.md)。

### 8.1 T4 价目清单（C-price，6 列 × 13 行）

| 区域 | kind | format | fractionDigits | unit | locked |
|---|---|---|---|---|---|
| R0:C0–C5 表名 `price.title` | 文本 | — | — | — | 合并 locked，文字可改 |
| R1 列头「序号 / 项目 / 规格 / 数量 / 单价 / 小计」 | 文本 | — | — | — | 只读 |
| G1 分隔槽：预置分组标题「材料」 | — | — | — | — | — |
| R2–R7 × C0 序号 1～6 | 文本 | — | — | — | 只读 |
| R2–R7 × C1 项目、C2 规格 | 文本 | — | — | — | 否 |
| R2–R7 × C3 数量 | 数字 | 千分位 | 0 | 模板可写「件」等，用户不可改 | 否 |
| R2–R7 × C4 单价 | 货币 | ¥ 前置 | 2 | — | 否 |
| R2–R7 × C5 小计 | 货币 | ¥ 前置 | 2 | — | 否（**不自动计算**，用户自填） |
| G2 分隔槽：预置分组标题「人工」 | — | — | — | — | — |
| R8–R11 | 同 R2–R7 各列 | | | | 序号 7～10 |
| R12 合计行：C0–C4 「合计」 | 文本 | — | — | — | 合并 locked，只读 |
| R12 × C5 合计金额 | 货币 | ¥ 前置 | 2 | — | 否（不自动计算） |

- recommendableCols：**否**（FR-23 只针对对比模板）。
- 允许合并区：无（价目清单不做合并）。首列钉：无（序号列窄，不钉；窄屏横滑时 C1 项目列钉住）。
- **3×4 连续粘贴测试区：R2–R5 × C3–C5（4 行 × 3 列：数量 / 单价 / 小计）**，无合并、无区块，可同时测数字和货币解析。

### 8.2 T3 宽表矩阵（C-matrix，6 列 × 11 行）

| 区域 | kind | format | fractionDigits | unit | locked |
|---|---|---|---|---|---|
| R0:C0 「条目」 | 文本 | — | — | — | 只读，**locked 合并 R0–R1** |
| R0:C1–C5 档位分组 `band.{n}` | 文本 | — | — | — | 否；**允许合并区 = R0:C1–C5 横向**，默认 C1–C2「基础」、C3–C5「进阶」 |
| R1 × C1–C5 档名 `tier.name.{a..e}` | 文本 | — | — | — | 否 |
| G1 分隔槽：预置分组标题「功能」 | — | — | — | — | — |
| R2–R6 × C0 条目名 | 文本 | — | — | — | 否 |
| R2–R6 × C1–C5 交叉值 | 符号（✓✗◐） | 主题 token | — | — | 否 |
| G2 分隔槽：预置分组标题「占比」 | — | — | — | — | — |
| R7–R10 × C0 条目名 | 文本 | — | — | — | 否 |
| R7–R10 × C1–C5 交叉值 | 百分比 | 一律存比例 | 未声明（按输入最多 2 位、末尾 0 不显示，Q-009） | — | 否 |

- recommendableCols：**否**（同上；如需矩阵也能标推荐列，由 PM 另提 FR-23 范围）。
- 首列钉：C0。表体不设允许合并区。
- **3×4 连续粘贴测试区：R2–R4 × C1–C4（3 行 × 4 列，符号槽）**，无合并、无区块，可测识别词（是/否/部分）。
