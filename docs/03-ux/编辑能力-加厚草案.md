## 0. 加厚目标（白话）

让编辑台感觉是「能改表」，不是「只能填空换色」。路径仍是模板表：

**选 → 改结构（允许范围内）→ 改单元格 → 反馈态**

不滑向：自由画布、真 Excel、任意增删行列。

## 2. 分条说明（用途 / 入口 / 空·成功态 / 与槽位关系）

### 2.1 选

#### TH-S1 · 点选单元格 / 区块 — **本期 IN**

| 项 | 内容 |
|----|------|
| 用途 | 明确「当前改的是谁」；属性栏有对象 |
| 入口 | 中间预览单击格或已落区块 |
| 空态 | 未选：「点选单元格或表内区块后，在此编辑」 |
| 成功态 | 选中描边；右侧切到对应属性 |
| 与槽位 | 点到文案槽 → 编辑槽；点到区块槽内块 → 编辑块；点到非槽结构格 → 仅允许区内可走合并/强调 |

#### TH-S2 · 多选相邻格（合并前）— **本期 IN**

| 项 | 内容 |
|----|------|
| 用途 | 合并前看清范围；避免「点一下就并」不知范围 |
| 入口 | 拖选或 Shift+点（桌面）；触控长按拖（若做移动端再定） |
| 空态 | 未形成合法区：工具条「合并」禁用 + 弱提示「选中模板允许合并的相邻格」 |
| 成功态 | 合法选区高亮；「合并」可点 |
| 与槽位 | 仅模板 `mergeAllow` 栅格内；跨禁止线不可选满 |

#### TH-S3 · 框选整行/列强调 — **后置**

用途：批量强调。易与 Excel 混淆，非 Fill，后置。

---

### 2.2 改结构

#### TH-R1 · 有限合并加厚 — **本期 IN**

| 项 | 内容 |
|----|------|
| 用途 | 用户点名能力：合并单元格；在模板划定区内完成 |
| 入口 | ① 选区后顶栏/属性「合并」② 允许区悬停出现「可合并」弱标 |
| 空态/失败 | 非允许区：「此处不能合并，请使用模板已开放的合并区」 |
| 成功态 | 格并成一块 + ≤200ms 边框闪；toast「已合并」；可立即改合并格文案 |
| 与槽位 | 合并后文案槽合并为 1 个（或保留主槽）；区块槽不可被合并「吃掉」——冲突则禁并并提示 |
| 禁暗示 | **不提供** Excel 拖角任意合并；入口为属性/工具条，对齐 OUT-9 |

#### TH-R2 · 拆分 — **本期 IN**

| 项 | 内容 |
|----|------|
| 用途 | 合错可退；增强可控感 |
| 入口 | 选中已合并格 →「拆分」 |
| 失败 | 模板锁定的预设合并且标 `locked`：「这是模板固定合并，不能拆」 |
| 成功 | 拆回栅格；toast「已拆分」 |
| 与槽位 | 用户自并的可拆；预设 locked 不拆（对齐版式清单） |

#### TH-R3 · 列宽拖拽 — **后置 · Mid（本期不做）**

入口：表头边界拖；吸附 3～5 档。属 Mid；与「结构锁死」略冲，本期不进 Fill。

#### TH-R4 · 有限增行 — **后置 · Mid · 须重开 OUT（本期不做）**

与 OUT「不增删行列」冲突。若未来升期：仅模板标 `rowExtendable` 的表体区、有上限（如 +3 行）。本期无入口、无交互细则。

#### TH-R5 · 任意增删 / Excel 拖角 — **不做**

保持禁操作文案（如「不支持增删行列」「此处不能像 Excel 那样拖角合并」）。本期无此类入口。

### 2.3 改单元格

#### TH-C1 · 就地编辑加厚 — **本期 IN**

| 项 | 内容 |
|----|------|
| 用途 | 内容自定义的主路径 |
| 入口 | 双击格 / 选中后右侧输入 / 焦点时直接键入 |
| 空态 | 占位：「填写…」（沿用体验深化 §2） |
| 成功态 | 预览 ≤200ms 同步；无整页闪 |
| 与槽位 | 只写槽位字段；非槽只读格点选给「此处由模板固定」 |

#### TH-C2 · 对齐切换 — **本期 IN**

| 项 | 内容 |
|----|------|
| 用途 | 微调观感，不改结构 |
| 入口 | 属性 · 对齐三钮；默认仍建议数字右/文案左 |
| 成功 | 预览即时；toast 可省 |
| 与槽位 | 按槽 `valueType` 给默认；用户可覆盖 |

#### TH-C3 · 强调 — **本期 IN**

| 项 | 内容 |
|----|------|
| 用途 | 「这格重要」一眼看出 |
| 入口 | 选中后属性「强调」或工具条色点 |
| 成功 | 底色/加粗可见；与主题 token 一致（无自定义 hex） |
| 与槽位 | 强调是实例态，另存模板时可一并写入（对齐 SAVE） |

#### TH-C4 · 数字格式 — **后置**

千分位/小数位；易变数据模型，非 Fill，后置。

### 2.4 区块（结构扩展，非画布）

#### TH-B1 · 拖入/替换/移除加厚 — **本期 IN**

沿用 U-6A + 体验深化 §3：高亮槽、命中淡入、占用替换 toast、移除二次确认。加厚点：拖起时预览幽灵块；禁止落点红色脉动一次。**表外/画布拖放不做**（见 TH-X1）。

#### TH-B2 · 区块样式微调 — **本期 IN**

选中区块 → 属性：色条深浅（3 档）、注脚字号（2 档）。仍无自由定位。

#### TH-B3 · 新区块种类 — **后置**

图标行、对比高亮条等，扩组件库时再开；非 Fill。

### 2.5 反馈态

#### TH-F1 · 撤销一步 — **本期 IN**（FR-11）

入口：顶栏撤销 / Ctrl+Z。覆盖文案/主题/合并/拆分/对齐/强调/区块。成功：预览回退；失败：已到头时按钮禁用。

#### TH-F2 · 禁操作 — **本期 IN**

沿用体验深化 §4 表。**须保留**对任意增删行列、非允许区合并、画布/表外拖放等的可读 toast；不暗示这些能力可做。

#### TH-F3 · 微动效 — **本期 IN**

合并闪边、落块淡入、主题切换轻淡入 ≤300ms；禁止整页 loading。

## 3. 与「只换肤」的差异（给用户看的一句话）

加厚后主路径仍是模板，但编辑台要能：**选中 → 在允许区合并/拆分 → 改字与强调 → 拖区块 → 撤销**，导出所见即所得。不是换个主题色就结束。
