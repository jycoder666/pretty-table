# 页面流：模板库 → 编辑台 → 导出

> 项目：pretty-table · 文档类型：UX 页面流 · 状态：**草案 · 已对齐已锁 Fill**（仍不开码）  
> 对齐：在线工具为主、预留嵌入；壳 + 渲染核分层；拖拽 = **表内槽位拖入**（非整页画布）  
> **Fill 锚点**：`编辑能力-加厚草案.md`（TH-S1/S2、R1/R2、C1/C2/C3、B1/B2、F1/F2/F3）；Mid/Heavy **本期不做**；**不重开 OUT**  
> 权威：`Documents\grok\pretty-table\docs\03-ux\页面流-模板库编辑台导出.md`

## 1. 页面总览

```
P1 模板库  →  P2 编辑台  →  P3 导出
```

| 页面 | 目标 | 核心产出 |
|---|---|---|
| **P1 模板库** | 选一张底稿开始 | 选中模板 ID / 进入编辑台 |
| **P2 编辑台** | 填槽、换皮、**允许区合并/拆分**、对齐/强调、区块拖入与样式微调 | 可预览的表格实例（Fill 饱满手感，非仅换肤） |
| **P3 导出** | 拿走结果 | HTML 剪贴板 / PNG 文件 |

本期**不做**：嵌入配置页、协作、账户体系（除非后续待确认纳入）；自由画布拼表；任意增删行列；Excel 拖角合并；Mid（列宽/有限增行）与 Heavy（筛排冻结填充柄等）。

## 2. P1 模板库

### 目标

从**多类型**预设底稿中选一张进入编辑；降低从空白表起步的成本。  
分类按**版式骨架**（多列对比 / 单主体明细 / 宽表矩阵…），**不按行业**；行业只体现在卡片用途文案或可选示例填充。细则见 `多类型模板库-交互口径.md`。

### 关键控件

- 模板卡片网格（缩略预览 + **类型小标签** + 名称 + 一句用途）
- **分区**：「我的模板」在上、「系统模板」在下（我的为空时保留段标题，显示唯一空态文案，见另存说明 §2.2）
- 分类 Chip：`全部` + 有模板的类型（≥2 类时显示）；首发可先「全部」
- 大预览：点卡片或悬停 → 只读预览（不创建实例亦可）
- 「使用此模板」主按钮 → 克隆实例进 P2（不改库内原件）
- 我的模板卡片菜单：删除（二次确认）
- 空态：无匹配时「没有这类模板，试试『全部』」+ 清空筛选；我的为空见 `另存为模板-交互说明.md`

### 状态要点

| 状态 | 要点 |
|---|---|
| 加载 | 卡片骨架屏或轻量 loading，避免白屏 |
| 空态 | 「暂无模板」+ 引导（非报错样式） |
| 筛选无结果 | 非错误态；给清空筛选 |
| 错误 | 「模板列表加载失败，请重试」；可点重试 |

## 3. P2 编辑台（对齐已锁 Fill）

### 布局（三栏 · U-6A）

```
┌──────────┬────────────────────┬──────────────┐
│ 左·组件库 │ 中·表格预览（渲染核） │ 右·属性面板   │
│ 表内区块  │ 槽位高亮 = 拖入落点  │ 文案/主题/合并 │
│          │ 选区 = 合并/对齐入口  │ 拆分/对齐/强调 │
└──────────┴────────────────────┴──────────────┘
```

| 区域 | 职责 |
|---|---|
| **左侧 · 组件库** | 仅列出**可拖表内区块**（与 `表格版式能力清单.md` §5.2 对齐）：分区色条、分组标题行、强调注脚、左栏标签块 |
| **中间 · 预览** | **渲染核挂载点**；拖入落点是表内**槽位 / 区块位**；点选/多选相邻格进入 Fill「选→改」路径；**不是**自由画布任意坐标 |
| **右侧 · 属性** | 槽位文案、主题/斑马纹、**合并/拆分**、**对齐三钮**、强调、区块色条深浅/注脚字号；无选中时空引导 |

### 3.1 Fill IN · 入口路径（编辑台主手感）

路径白话：**选 → 改结构（允许范围内）→ 改单元格 → 反馈**。细则与文案以 `编辑能力-加厚草案.md` §2 为准；此处只钉页面流入口。

| 步骤 | TH | 入口路径 | 空选 / 失败态（短） | 成功微反馈 |
|---|---|---|---|---|
| 点选 | S1 | 中间预览单击格或已落区块 | 右栏：「点选单元格或表内区块后，在此编辑」 | 选中描边；右栏切对象 |
| 多选（合并前） | S2 | 拖选或 Shift+点相邻格（桌面） | 「合并」禁用 + 弱提示「选中模板允许合并的相邻格」 | 合法选区高亮；「合并」可点 |
| 有限合并 | R1 | ① 合法选区后顶栏/属性「合并」② 允许区悬停「可合并」弱标 | 「此处不能合并，请使用模板已开放的合并区」 | 并成一块 + ≤200ms 边框闪；toast「已合并」 |
| 拆分 | R2 | 选中已合并格 →「拆分」 | 预设 `locked`：「这是模板固定合并，不能拆」 | toast「已拆分」；回栅格 |
| 就地改字 | C1 | 双击格 / 选中后右栏输入 / 焦点键入 | 占位「填写…」；非槽只读：「此处由模板固定」 | 预览 ≤200ms 同步 |
| 对齐 | C2 | 选中后属性「对齐」左/中/右三钮 | 无选中：对齐钮禁用（跟空引导） | 预览即时；toast 可省 |
| 强调 | C3 | 选中后属性「强调」或工具条色点；控件只有红字/加粗/底色三项（Q-004） | 无选中或选中禁止强调区（表头、左栏项名、只读格、区块）：强调控件禁用 | 底色/加粗可见；与主题 token 一致 |
| 区块拖入 | B1 | 左库拖入 / 点击添加（G-UX-05） | 未命中槽：「请放到表内虚线槽位」 | 落成淡入；占用则「已替换原区块」 |
| 区块样式微调 | B2 | 选中区块 → 属性：色条深浅 3 档、注脚字号 2 档 | 未选区块：该项隐藏或灰显 | 预览即时；仍无自由定位 |
| 撤销 | F1 | 顶栏撤销 / Ctrl+Z | 已到头：按钮禁用 | 预览回退（含合并/拆分/对齐/强调/区块） |
| 禁操作 | F2 | 无入口为优；误触见下方禁操作表 | 白话 toast，不弹错误码 | — |
| 微动效 | F3 | 合并闪边、落块淡入、主题轻淡入 ≤300ms | — | **禁止**整页 loading |

**Mid / Heavy 本期无入口**：列宽拖拽（R3）、有限增行（R4）、筛排/冻结/填充柄等 —— 页面流不出现控件，细节后置。

### 3.2 空选态（属性栏）

| 条件 | 右栏表现 | 文案 |
|---|---|---|
| 未选中任何格/区块 | 空引导；合并/拆分/对齐/强调禁用 | 「点选单元格或表内区块后，在此编辑」 |
| 多选未形成合法合并区 | 可显示选区提示；「合并」禁用 | 「选中模板允许合并的相邻格」 |
| 选中非槽只读结构格 | 说明只读；允许区内仍可走合并/强调 | 「此处由模板固定」或仅开放允许操作 |

### 3.3 禁操作 toast / 文案（与加厚草案一致 · 不重开 OUT）

| 用户意图 | 反馈文案 | 入口策略 |
|---|---|---|
| 任意增删行列 | 「当前模板不支持增删行列」 | **无入口** |
| Excel 拖角任意合并 | 「此处不能像 Excel 那样拖角合并」 | **无拖角**；合并仅属性/工具条 |
| 非允许区合并 | 「此处不能合并，请使用模板已开放的合并区」 | 「合并」禁用或点后 toast |
| 拆模板锁定预设合并 | 「这是模板固定合并，不能拆」 | 「拆分」禁用或 toast |
| 自由画布 / 表外拖放 | 「请放到表内虚线槽位」（与未命中槽同句即可） | **无画布入口、无开关** |
| 公式 / 填充柄 / 筛排冻结 | — | **无入口**（Heavy 本期不做） |
| Excel 导出 | 「本期请用 HTML 或 PNG」 | 导出区不出现 Excel |

### 拖入交互要点（U-6A · TH-B1）

- 从左侧拖到中间预览：仅当指针命中模板预留槽位时显示「可放置」高亮
- 未命中槽位松手 → 回弹组件库，短提示「请放到表内虚线槽位」
- 落成后仍是**同一张表**；禁止在预览区外（页面空白、侧栏）落块
- 拖起时预览幽灵块；禁止落点可红色脉动一次（加厚手感）
- 详情与禁止项见 `表格版式能力清单.md` §5

### 区块增删与点击添加（G-UX-05 · 对齐 FR-09 · TH-B1）

| 动作 | 约定 |
|---|---|
| 选中 | 点击已落入的表内区块 → 预览描边高亮；右侧属性切到该区块文案/样式（含 B2 微调） |
| 改文案 | 属性面板编辑；失焦写回实例；预览同步 |
| 删除 | 属性面板「移除区块」或选中后 Delete；二次确认：「移除后可从左侧重新拖入」 |
| 同槽再拖入 | **与需求假设对齐：替换**（先清旧块再落入新块）；toast「已替换原区块」 |
| 点击添加（辅助，非画布） | ① 单击组件库某项（进入「待放置」态）→ ② 再单击高亮槽位 → 等同拖入落成；Esc 取消待放置。便于触控/键盘用户，**不是**自由点击画布 |
| 键盘 | Tab 在属性表单字段间移动；Esc 取消拖拽中/待放置；撤销一步见需求 FR-11 / TH-F1 |
| 键盘放区块（2026-10-20 补） | 走「点击添加」：组件库项上按 Enter 进入待放置 → 焦点跳到第一个可放槽位，↑↓ 或 Tab 在可放槽位间移动（只经过高亮槽，跳过表格格子）→ Enter 放下，Esc 取消；屏幕阅读提示「第 2 个槽位，共 3 个，按回车放入」。键盘**不做**按住拖动 |

### 目标

在模板约束内完成「好看、可用、能改结构（允许范围）」的表；所见即所得。**不是**只能填空换色。

### 关键控件（Fill 齐全）

- 预览区（渲染核）：点选 / 多选相邻格
- 左侧组件库托盘（上列 4 类；首发至少上线 2 类）
- 槽位表单或点选单元格后编辑（C1）
- 顶栏/属性：**合并**、**拆分**（R1/R2）
- 属性：**对齐**三钮（C2）、强调（C3）、主题、斑马纹
- 选中区块：色条深浅、注脚字号（B2）
- 顶栏：**撤销**（F1）、「另存为模板」、「导出」

### 状态要点

| 状态 | 要点 |
|---|---|
| 加载 | 预览区占位 + 「表格渲染中」 |
| 空态 | 理论上从 P1 进入必有模板；若无，回退提示「请先选模板」 |
| 错误 | 渲染失败时保留左右侧栏，预览区显示错误与重试；勿整页崩 |
| 拖入失败 | 未命中槽位时不落块 + 短提示（非报错红屏） |
| 空选 | 右栏空引导；结构/强调类控件禁用（§3.2） |
| 禁操作 | 白话 toast（§3.3）；不暗示可做 Mid/Heavy/画布 |
| 已恢复 | 刷新/重开后自动恢复最近一次编辑（P-1 已确认）；见下方「刷新恢复」 |
| 恢复失败（`DRAFT_RESTORE_FAIL`） | 本地数据读不出或已损坏时，按模板初始状态打开，顶部提示「上次的编辑没能恢复，已按模板重新打开」，不弹窗、不报红；若连原模板也找不到，回 P1 模板库并提示「上次用的模板找不到了，请重新选一张」 |
| 自动保存失败（`DRAFT_SAVE_FAIL`） | 不打断编辑；本次打开期间只在顶部轻提示一次「自动保存没成功，刷新后可能找不回，建议先另存为模板或导出」，5 秒后收起 |

### 刷新恢复（P-1 已确认 · 2026-10-20）

| 项 | 规则 |
|---|---|
| 范围 | 同一浏览器只保留**最近一份**编辑中的表；另存为模板的内容不受影响（在「我的模板」里） |
| 何时存 | 每次改动后自动存，用户无感，不显示「保存中」 |
| 重开入口 | 打开站点时若有未完成的编辑，直接进 P2 编辑台并恢复；顶部细条提示「已恢复上次的编辑」+ 文字按钮「不恢复，重新选模板」，8 秒后或开始编辑后自动收起 |
| 点「不恢复」 | 二次确认「放弃上次的编辑？放弃后找不回」→ 确认后清掉这份记录，回 P1 模板库 |
| 撤销 | 恢复后撤销按钮为灰（撤销记录不跨刷新） |
| 从 P1 选新模板 | 若已有一份未完成编辑，确认「开始新表会替换上次没做完的那份」；取消则留在 P1 |
| 离开确认（FR-10） | 文案改为「离开后，没另存为模板的改动只保留最近一份，可下次打开时继续」；关页仍走浏览器自带确认 |

### 与「壳 + 渲染核分层」的 UX 含义

- **预览区 = 渲染核挂载点**：只负责把「模板 JSON + 槽位数据 + 主题 + 已落成区块 + 允许区合并态」渲染成表
- **壳**（导航、组件库、属性面板、合并/对齐入口、导出）**不写死表 DOM**；DnD / 合并由壳层写入实例数据，核只渲染
- 预留嵌入时：宿主可只挂载同一渲染核；本期壳做成完整在线工具即可

## 4. P3 导出

### 4.1 形态定档（G-UX-02）

| 项 | 当前假设（待确认 · 对齐 UX-T1） |
|---|---|
| **定档** | **P2 内右侧抽屉** 作为首发形态（不强制跳独立页） |
| 等价说明 | 独立 P3 页与抽屉 **交互等价**；若实现改独立页，文案/状态表仍适用 |
| 入口 | 编辑台顶栏主按钮「导出」→ 打开抽屉 |
| 关闭 | 点遮罩 / Esc / 「完成」；关闭不丢编辑台内容 |

### 4.2 目标

把当前预览结果带走，用于网页粘贴或图片分享。

### 4.3 关键控件与文案

- 「复制 HTML」→ 成功 toast「已复制到剪贴板」；可附一句「可粘贴到介绍页或邮件」
- 「下载 PNG」→ 触发下载；可选 toast「开始下载」
- 可选：抽屉内小预览（默认同编辑台所见）
- Excel：**不出现入口**

### 4.4 状态要点（含防连点）

| 状态 | 要点 | 文案 |
|---|---|---|
| 默认 | 双按钮可用（预览就绪时） | — |
| 预览未就绪 | 双按钮禁用 | 「请等待表格渲染完成」 |
| HTML 进行中 | 按钮 loading，防连点 | — |
| HTML 成功 | toast 3s | 「已复制到剪贴板」 |
| HTML 失败 | 行内错 + 重试 | 「复制失败，请重试」 |
| PNG 进行中 | 按钮禁用 + 短进度，防连点 | 「正在生成图片…」 |
| PNG 成功 | 下载开始 | 可选「开始下载」 |
| PNG 失败 | 行内错 + 重试 | 「导出失败，请重试」 |

空槽较多：**不二次确认**（对齐体验深化 UX-T4 / 需求假设）；直接导出空字符串，不输出占位句。

## 5. 主路径用户故事（1 条 · Fill）

> 作为要做对比表的同学，我在 **P1** 按类型选中一张「多列对比」底稿，在 **P2** 点选/多选允许区格子完成合并与拆分、填文案、调对齐与强调、从左侧拖入分区色条并微调色条深浅，换主题后撤销误操作，再导出 HTML 或 PNG；需要下次复用时点「另存为模板」。全程**不能**任意增删行列、**不能**当 Excel 拖角合并、**不能**当自由画布乱摆。

**Fill 验收对齐（文档口径）**：在允许区完成「选区→合并→改字→拆分→对齐→强调→另存→HTML/PNG」；非允许区仅禁操作提示；无增删行列入口；无画布入口。

## 7. 本期明确不做（页面级）

- 嵌入 SDK / 宿主配置页
- 多人协作、评论、权限
- 账户登录与云端保存（除非后续待确认纳入）
- **自由画布、表外组件拼装页**（U-6 已排除 D；画布属后置 · TH-X1）
- **任意增删行列 / Excel 拖角合并**（OUT · TH-R5）
- **Mid**：列宽拖拽、有限增行（须另议重开 OUT）——本期无入口
