## 0. 共用原则（增强期新增）

| # | 原则 | 含义 |
|---|---|---|
| P1 | 先看后写 | 粘贴一律先预览落位，用户点「确认」才进 store；取消不留痕 |
| P2 | 整块或不动 | 任何一格写不进去，整块都不写；不截断、不扩表、不半成品（对齐路线 A「不半更新」） |
| P3 | 结构不随数据变 | 粘贴只改槽位里的字，不改行列数、合并、区块 |
| P4 | 样式只跟主题 | ✓✗◐、数值、推荐列的颜色全部取 T-A/B/C 的 token；界面不出现取色器、符号库、hex 输入 |
| P5 | 导出 = 所见 | 倍率、透明底只改「图片怎么出」，不改表的样子；HTML 与 PNG 仍只读同一份 store |

## 1. 粘贴填槽（FR-16～19 · ② 入口提速）

### 1.1 入口

| 入口 | 触发条件 | 说明 |
|---|---|---|
| 快捷键 | 预览里**选中**一个可写槽位（描边态，非输入态）→ Ctrl+V / Cmd+V | 主入口；选中格 = 起点（左上角） |
| 工具条按钮「粘贴表格内容」 | 有选中可写槽位时可点；未选中时禁用，悬停提示「先点一个格子作为起点」 | 点后弹小框「在这里粘贴（Ctrl+V）」，粘入即进预览；给不熟快捷键的人和浏览器不让读剪贴板的情况兜底 |
| 输入态里粘贴 | 正在某格里打字时 Ctrl+V | **按普通文字粘进这一格**，不走填槽；若内容含多格（制表符/换行），格下方行内提示「这是多格内容。按 Esc 退出编辑后再粘贴，可按格子依次填入」 |

不提供：右键菜单「从文件导入」、拖文件进预览、「粘贴并扩展表格」——OUT-5②、OUT-1/10。

### 1.2 主流程

```
选中起点格 → Ctrl/Cmd+V（或工具条）→ 预览落位 → 确认写入 / 取消
                                       └→ 不可写时：整块拒收提示（不进预览确认）
```

| 步 | 界面 | 文案 |
|---|---|---|
| ① 识别 | 读剪贴板，去掉末尾空行空列（Excel 复制常带一个尾换行） | — |
| ② 预览落位 | 将写入的格子盖一层**半透明主题浅色**（取 `zebra` 色加深一档的透明叠加，不新增 hex），格内以浅灰斜体显示**新值**；起点格加粗描边；块外表格略压暗 | 预览条（表格上方贴边）：「将填入 3 行 × 4 列，共 12 格」 |
| ③ 确认 | 预览条右侧「确认写入」（主按钮，Enter）/「取消」（Esc） | — |
| ④ 写入成功 | 覆盖层淡出 ≤200ms；被改的格边框轻闪一次 | toast「已填入 12 格」+ 文字按钮「撤销」 |
| ⑤ 撤销 | 顶栏撤销 / Ctrl+Z / toast 里的「撤销」，**一步**回到粘贴前所有格 | toast「已撤销粘贴」 |

预览期间：合并/拆分/对齐/强调/拖区块/导出全部禁用（灰显，悬停「先确认或取消这次粘贴」）；点表格外或其它格 = 取消，不改任何东西。

### 1.3 全状态与文案

| # | 状态 | 判定（体验口径） | 界面表现 | 文案 | 写入？ |
|---|---|---|---|---|---|
| S1 | 正常（刚好或少于可写范围） | 块内每格都落在可写槽位 | 正常预览 | 预览条「将填入 {r} 行 × {c} 列，共 {n} 格」 | 确认后写 |
| S2 | 少粘 | 块比剩余可写区小 | 只盖块内格；块外格不盖层、保持原值（E-3） | 同 S1；不额外提示 | 只写块内 |
| S3 | 多粘 / 超出可写范围 | 从起点往右或往下装不下 | **不进预览确认**；超出的部分在表格边缘外画一圈红色虚线「幽灵格」示意多出多少，2s 后消失 | toast：「放不下：多出 1 列。表格不会自动加列，请少复制 1 列，或换个更靠左的起点」（行同理：「多出 2 行…加行…更靠上…」；行列都超：「多出 2 行 1 列…」） | 不写 |
| S4 | 碰到合并格（E-1 已确认） | 块内任一格落在合并格上（模板预置或用户自并） | 冲突格红色描边，其余不盖层 | toast：「这块区域里有合并的格子，没法按格填入。请先拆分，或换个起点」 | 不写 |
| S5 | 碰到锁定格 / 模板固定格（E-1 已确认） | 块内有 `locked` 合并、或「此处由模板固定」的只读格 | 同 S4 | toast：「这块区域里有模板固定的格子（不能改），请换个起点」 | 不写 |
| S6 | 碰到区块行（E-1 已确认：整块拒收） | 块跨过分区色条 / 分组标题行 | 区块行红色描边 | toast：「这块区域跨过了分区色条，没法连着填。请分两次粘贴，或先移除色条」 | 不写 |
| S7 | 源里有空单元格（E-8 已确认） | 块内某格为空字符串 | 预览里该格显示「（将清空）」浅灰字 | 预览条追加一句：「其中 2 格为空，确认后会清空」 | 确认后写空（导出为空，UX-T2） |
| S8 | 行长短不齐 | 各行列数不一 | 按最长一行算块宽；短行缺的格**不盖层、不改**（同 S2 口径） | 不额外提示 | 只写有值格 |
| S9 | 只有一格（1×1，E-11 已确认） | 无制表符、无换行 | 不弹预览，直接写入起点格（等同改字） | 无 toast；可撤销 | 写 |
| S10 | 非表格内容 | 剪贴板是图片/文件/无文字，或全是空白 | 不进预览 | toast：「剪贴板里没有可用的表格文字。请在 Excel / WPS 里选中单元格复制后再粘贴」；若是文件，补一句「暂不支持直接导入文件」 | 不写 |
| S11 | 浏览器不让读剪贴板（仅工具条入口） | 权限被拒 | 自动改为弹小框让用户手动 Ctrl+V | 小框标题「在这里粘贴（Ctrl+V）」 | — |
| S12 | 起点不可写 | 选中的是只读格 / 表头固定格 / 区块 | 「粘贴表格内容」禁用；按快捷键时 toast | 「这个格子不能填写，请选一个可填写的格子作为起点」 | 不写 |
| S13 | 写入失败（确认后） | store 校验未过等任何失败 | 覆盖层撤掉，表格完全是粘贴前的样子 | toast：「这次粘贴没有成功，表格保持原样。请重试」+「重试」 | 整体回滚，一格不写 |
| S14 | 撤销 | 写入成功后撤销一步 | 所有被改格恢复；格子轻闪 | 「已撤销粘贴」 | 回原样 |
| S15 | 撤销到头 | 已撤过 | 撤销按钮禁用 | — | — |

**拒收提示的原则**：说清「多了什么 / 卡在哪」+「怎么做能成」；不说「错误」「非法」「越界」；不露码。

### 1.4 粘贴内容的识别（E-2 词表）

只在模板声明为**符号槽**的格子里识别；普通文字槽里一律按原文写入。忽略首尾空格、大小写。

| 粘贴原文（任一） | 识别为 | 预览显示 |
|---|---|---|
| ✓ ✔ √ 是 有 支持 Y Yes TRUE | ✓ 支持 | ✓ |
| ✗ ✘ × 否 无 不支持 N No FALSE | ✗ 不支持 | ✗ |
| ◐ 部分 部分支持 Partial | ◐ 部分 | ◐ |
| 其它文字（如「仅限会员」） | 不识别，按文字写入 | 原文 + 预览条追加「其中 1 格不是 ✓✗◐，按文字填入」 |

数值槽（Q-011，对齐需求 §6.2）：各类槽能读成数字的内容才按数值写入、再按模板格式显示，读法见 §4.3 输入表；读不成的（如「面议」，或数字槽里带 `%`/`¥`/`元`）一律**按文字原样写入，不整块拒收**。这类格子在编辑台右上角显示灰色小标「按文字」（导出不带），预览条追加一句「其中 N 格按文字填入」。

### 1.5 E-1 结论（已确认）

| 子项 | 结论 | 说明 |
|---|---|---|
| 合并格 | 整块拒收 | 合并格「一格顶多格」，按位置填必然对不上，拒收最不意外 |
| 锁定格 / 模板固定格 | 整块拒收 | — |
| 区块行（分区色条、分组标题行） | 整块拒收 | 交互曾建议「跳过区块行、按数据行顺排」，群拍未采纳。S6 文案即终稿；FR-18「超出」按用户看到的格子行列数算，区块行算 1 行（Q-020）；同时跨区块/合并又超出时，一次提示两条原因，区块/合并原因在前，例：「粘贴范围压到了分区色条行，请先拆开粘贴；另外多出 1 列」 |

留档：若日后用户反馈「每次都要分两段粘」，可凭此条重开讨论，不在本期改。

## 2. 价目 / 矩阵模板入口（FR-20）

### 2.1 模板库类型筛选

与现有 α 类型并列，按骨架分类不按行业（沿用 [多类型模板库-交互口径](./多类型模板库-交互口径.md) §1）：

| Chip 顺序 | 类型 ID | Chip 文案 | 状态 |
|---|---|---|---|
| 1 | — | 全部 | 已有 |
| 2 | C-compare | 多列对比 | 已有（α） |
| 3 | C-detail | 单主体明细 | 已有（α） |
| 4 | C-price | 价目清单 | **增强期新增** |
| 5 | C-matrix | 宽表矩阵 | **增强期新增** |

- 有模板才显示 Chip（UX-CAT-d 不变）。新增两类上线后的前 2 周，卡片类型标签旁加小角标「新」，不做弹窗推广。
- 「我的模板」段同样按 Chip 过滤；用户另存的价目表归「价目清单」。

### 2.2 卡片

| 类型 | 卡片名称（样例，可改） | 一句用途 | 卡片小字（防误解） |
|---|---|---|---|
| C-price | 服务报价单 | 项目、数量、单价、小计，一张表说清价格 | 「行数由模板定好；小计请自己填写，不会自动计算」 |
| C-matrix | 档位矩阵 | 多档位 × 多条目，适合权限、套餐档、评测打分 | 「列多时左右滑动，首列固定」 |

- 「不会自动计算」必须写：价目表最容易让人以为有公式（OUT-2）。
- 缩略图用真实样例文案（U-1 = A 通用商务），不放空表，避免像「新建空白表格」。
- 不出现「自由排版」「新建空白」「拖出任意表格」字样；与另外两类一样走「使用此模板」→ 编辑台。

### 2.3 空态

| 场景 | 文案 | 操作 |
|---|---|---|
| 选「价目清单」但系统未上架（灰度期） | 不显示该 Chip（不给空 Chip） | — |
| 「我的模板」里该类为空 | 「还没有存过价目清单模板。选一张系统模板改好后，点『另存为模板』就会出现在这里」 | — |
| 筛选无结果 | 「没有这类模板，试试『全部』」 | 「清空筛选」 |

### 2.4 进编辑台后

两类都支持 §1 粘贴填槽与 §3 导出；C-matrix 默认首列钉住。区块槽、允许合并区沿用槽位清单口径（逐格声明见 U-1 §3、§7，Q-012）。

## 3. 导出选项（FR-24～26 · ① 出口打磨）

### 3.1 抽屉布局（沿用 P2 右侧抽屉，UX-T1）

```
┌ 导出 ─────────────────────── ✕ ┐
│ [小预览：当前表，所见即所得]      │
│                                  │
│ ▍网页 / 文档                     │
│  [复制 HTML]                     │
│  小字：自带标题和表头，粘到公众号、│
│        邮件、文档里结构不乱       │
│                                  │
│ ▍图片                            │
│  清晰度  ( 1x | ●2x | 3x )       │
│          约 1840 × 960 像素       │
│  透明背景  [ 关 ]                 │
│  [下载 PNG]                      │
│                                  │
│ （FR-27 若纳入：▸ 更多格式 → 复制 Markdown） │
│                         [完成]   │
└──────────────────────────────────┘
```

| 控件 | 默认 | 规则 |
|---|---|---|
| 清晰度（倍率） | **2x**（FR-24） | 分段按钮 1x / 2x / 3x；下方实时显示输出像素；记住上次选择（本机，仅此浏览器） |
| 透明背景 | 关 | 开关；开启后小预览外围显示灰白棋盘格示意透明 |
| 复制 HTML | — | 无额外选项（语义结构、内联样式、窄屏适配都默认带上，不让用户选） |
| Excel | **不出现** | 同本期 |

### 3.2 PNG：倍率与透明底

| 情况 | 提示（选项下方小字） |
|---|---|
| 选 1x | 「适合网页小图」 |
| 选 2x | 「适合方案书、PPT（推荐）」 |
| 选 3x | 「适合打印或大屏；文件较大」 |
| 3x 且输出边长 > 6000 像素 | 「图片较大，生成可能要几秒」 |
| 开透明背景 | 「只去掉表格外围的底色，格子里的纸色保留。放到深色幻灯片上也能看清」 |
| 开透明 + 斑马纹关 | 同上（格子仍用纸色 `paper`，不会变成透明字悬空） |

说明：三套主题（T-A/B/C）都是浅纸色，没有深色主题；透明提示针对的是「放到深色背景上」这个使用场景，而不是主题本身。

### 3.3 HTML 语义化（体验层要求）

只写「复制后在文档里可读」的验收体感，结构细节归架构：

| 要求 | 用户能感知到的结果 |
|---|---|
| 表标题 | 模板标题槽有字时，粘贴后表格上方带标题；为空则不输出（不泄占位句，UX-T2） |
| 表头可识别 | 粘到支持表格的编辑器后，首行（及多级头）被当作表头：加粗、读屏能按列名朗读每格 |
| 行表头 | 对比/矩阵的首列项名被当作该行的标题，读屏读到「保费 · 方案 B · 1,200 元」这样的组合 |
| 合并保留 | 跨行跨列合并粘过去后仍合并 |
| 样式随身 | 主题色、斑马、强调、✓✗◐ 颜色都写在表格自身上，粘到没有样式表的页面也一样 |
| 符号不丢 | ✓✗◐ 以文字字符输出；被编辑器去掉颜色时仍能读出符号 |
| 推荐角标 | 「推荐」以文字出现在列头里，不只靠颜色或图片 |

富文本编辑器的验收对象见 E-6（§5）。

### 3.4 窄屏 ≤375px（FR-26 / E-4）

| 项 | 规则 |
|---|---|
| 页面 | 复制出的 HTML 外层自带「横向滚动容器」，整页不出现横向溢出 |
| 表格 | 容器内左右滑动；首列（或模板规定的标签列）钉住 |
| 可滑提示 | 容器右边缘一道淡出阴影，表示右边还有；滑到底阴影消失；左侧有被滑走的内容时左边缘出现同样阴影 |
| 钉列提示 | 首列右侧一条细分隔阴影，滑动时可见，说明这列是固定的 |
| 不做 | 不改成卡片式、不折行重排（会与 PNG/预览不一致，破坏「导出 = 所见」） |
| 编辑器去样式时 | 若目标编辑器去掉了钉列样式：退化为整表横滑，仍不撑破页面；这是可接受下限（依赖 E-6 选定的编辑器实测） |

编辑台内预览不变（桌面优先，§9 终端假设）。

### 3.5 抽屉状态与文案

| 状态 | 表现 | 文案 |
|---|---|---|
| 预览未就绪 | 所有按钮与选项禁用 | 「请等待表格渲染完成」 |
| 粘贴预览中打开导出 | 「导出」按钮本身禁用 | 悬停「先确认或取消这次粘贴」 |
| HTML 复制中 | 按钮 loading，防连点 | — |
| HTML 成功 | toast 3s | 「已复制到剪贴板，可直接粘贴到文档或网页」 |
| HTML 失败 | 行内错 + 重试 | 「复制失败，请重试」 |
| HTML 剪贴板被浏览器拒绝 | 行内错 + 展开手动复制框 | 「浏览器没有允许写入剪贴板，请在下方框里全选后手动复制」 |
| PNG 生成中 | 「下载 PNG」变「正在生成图片…」并禁用；倍率、透明开关同时禁用；HTML 仍可用 | 「正在生成图片…」 |
| PNG 成功 | 浏览器开始下载 | toast「图片已开始下载（2x，1840 × 960）」 |
| PNG 失败 | 行内错 + 重试；选项恢复可用 | 「图片生成失败，请重试」 |
| PNG 因太大失败（3x） | 行内错 + 一键改 2x | 「图片太大没能生成，试试 2x」+ 按钮「改用 2x 重试」 |
| 关闭抽屉 | 点遮罩 / Esc / 完成；不丢编辑内容 | — |

## 4. ✓✗◐ 符号与数值格式（FR-21～23）

### 4.1 三态符号（FR-21）

| 符号 | 含义 | 读屏 / 替代文字 | 颜色（取 U-2 token） | 形状区分 |
|---|---|---|---|---|
| ✓ | 支持 | 「支持」 | `primary` | 对勾 |
| ✗ | 不支持 | 「不支持」 | `emphasis` | 叉 |
| ◐ | 部分支持 | 「部分支持」 | `primary` | 半实心圆 |

| 主题 | ✓ / ◐ | ✗ |
|---|---|---|
| T-A 蓝白台账 | `#2F5B9A` | `#C0392B` |
| T-B 墨青簿册 | `#2F4F45` | `#A65B2A` |
| T-C 暖灰金 | `#4A463F` | `#8A6A2F` |

（色值只是引用 [U-2](./U-2-主题色板-草案.md) §1，不新增 hex；U-2 改则跟改。）

规则：
- 靠**形状**区分三态，颜色只是加强；黑白打印仍分得清。
- 符号槽在编辑台里的编辑方式：选中格后右栏出现三个按钮「✓ 支持 / ✗ 不支持 / ◐ 部分」+「清空」；也可打字，按 §1.4 词表识别。
- 符号槽也允许写文字（如「仅限会员」），按普通文字显示。
- 不提供：符号库、换图标、改颜色、加第四态（OUT-13）。
- 范围：对比类模板（FR-21）+ 宽表矩阵模板（E-10 已确认开放符号槽，规则同本节）。

### 4.2 推荐列（FR-23）

| 项 | 规则 |
|---|---|
| 入口 | 对比模板中选中某列的列头（对象名格）→ 右栏开关「设为推荐」 |
| 样子 | 列头右上角文字角标「推荐」（底 `emphasis`，字 `headerText`）；整列加一层极浅底（`emphasis` 的浅底，T-A 即 U-2 已列的 `#FDECEA`，其它主题用同档浅底）；与斑马纹叠加时推荐列浅底优先 |
| 最多一列 | 已有推荐列时再设另一列：自动转移，toast「推荐已改为『方案 B』」；可撤销一步回到原列 |
| 取消 | 关掉开关即可；无 toast |
| 角标文字 | 固定「推荐」，本期不可改（避免变成自定义标签） |
| 读屏 | 列头读作「方案 B（推荐）」 |
| 导出 | HTML、PNG 都带角标（§3.3） |
| 高亮列 | 不另设「高亮列」能力；「突出一列」= 推荐列。单格突出继续用 Fill 的强调 |

### 4.3 数值格式（FR-22）

格式由模板声明到槽位，用户不能切换格式类型（避免变成 Excel 格式面板）。

| 项 | 数字 | 百分比 | 货币 |
|---|---|---|---|
| 示例（存值 → 显示） | 1234567 → 1,234,567 | 存 0.25 → 显示 25%（一律存比例） | 1200 → ¥1,200.00 |
| 千分位 | 有 | 整数部分 ≥1000 时有 | 有 |
| 小数位 | 模板定（默认 0） | 模板声明固定位数时按模板；**未声明时按输入保留、最多 2 位、末尾 0 不显示**（`0.25`→0.25%，`33.333`→33.33%，Q-009） | 模板定（默认 2） |
| 四舍五入 | 按小数位四舍五入显示；存值不改 | 同左 | 同左 |
| 单位 | 模板可带后缀单位（如「元/月」「万」），数字与单位间留窄空格；单位用户不可改 | 不另加单位 | 符号前置（默认 ¥）；不再加「元」 |
| 负数 | 前置减号「-1,200」；不用括号，不变红（条件着色属 OUT-13） | 「-5%」 | 「-¥1,200.00」 |
| 空值 | 编辑台显示占位（如「填写金额」）；导出为空，不出现 0 或占位句（UX-T2） | 同左 | 同左 |
| 非数字文字 | 原样显示，不套格式（如「面议」） | 同左 | 同左 |
| 对齐 | 默认右对齐（沿用 Fill 对齐默认），用户仍可改 | 同左 | 同左 |

输入与粘贴时的读法：

| 用户输入 / 粘贴 | 数字槽 | 百分比槽 | 货币槽 |
|---|---|---|---|
| `1,234.5` | 1,235（0 位小数） | 1,234.5%（裸数字按百分数字面理解，Q-011） | ¥1,234.50 |
| `25%` | 按文字原样显示 + 标「按文字」 | 25% | 按文字原样显示 + 标「按文字」 |
| `0.25` | 0 | 0.25%（裸数字按百分数字面理解，见下行） | ¥0.25 |
| `25` | 25 | **25%**（E-9 已确认：裸数字按百分数字面理解；存比例 0.25；**不额外提醒**，预览格里直接显示 25%，Q-010） | ¥25.00 |
| `¥1,200` / `1200元` | 按文字原样显示 + 标「按文字」（Q-011） | 按文字原样显示 + 标「按文字」 | ¥1,200.00 |
| `$1,200` | 按文字 + 标「按文字」 | 按文字 + 标「按文字」 | 按文字 + 标「按文字」（本期货币符号只认 ¥） |
| `面议` 等非数字 | 按文字 + 标「按文字」 | 同左 | 同左 |

右栏格式说明（只读一行小字）：「这一格按货币显示，保留 2 位小数」——让用户知道为什么显示和输入不同。
