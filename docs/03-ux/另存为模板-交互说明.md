# 另存为模板 · 交互说明

> 项目：pretty-table · 文档类型：UX · 状态：**已锁（SAVE-default 草案全收）**  
> 对齐：U-6A 槽位制；**无自由画布**；UX-CAT-a 已锁 α（对比+明细）  
> 范围：壳侧「另存为模板」+ P1「我的模板」；持久化=本机（架构 §6.1）；本文定体验

---

## 0. 用户要什么

改完一张表后，**另存成自己的模板**，下次从库里再开、再改。  
不是自由画布，不是改系统预设原件。

---

## 1. P2 · 另存为模板

### 1.1 入口

| 位置 | 控件 | 说明 |
|---|---|---|
| 编辑台顶栏 | 次按钮「另存为模板」 | 与「导出」「换模板」并列；**不是**主按钮（主按钮仍是导出） |
| 更多菜单（可选） | 同名项 | 窄屏可收进「⋯」 |

无「画布」「自由放置」入口。

### 1.2 命名弹层

| 字段 | 规则 |
|---|---|
| 模板名称 | 必填；默认「{原模板名} 的副本」或「未命名模板」；**上限 40 字**，输入到 40 字后不能再输入，框右显示「n/40」；去掉首尾空格后为空时「保存」禁用，框下提示「请填写模板名称」（Q-013） |
| 类型标签 | **只读**，继承当前骨架（C-compare / C-detail…）；用户不能在此改成画布 |
| 说明（可选） | 一句用途，出在 P1 卡片副文案 |

| 操作 | 行为 |
|---|---|
| 取消 / Esc | 关闭，不写库 |
| 保存 | 校验非空名 → 写入「我的模板」→ 成功反馈 |

**重名（UX-SAVE-a 已锁）：允许保存。**  
若库内已有同名「我的」：弹层内弱提示「已有同名模板，可改名或保存后自动加后缀（如「副本 2」）」——**不拦死**；确认保存后写入；列表用「名称 + 保存时间」区分。
**后缀规则（Q-013 定稿）**：不改名直接保存时，卡片名自动在末尾加「空格 + 最小未占用的数字」，从 2 起（如「多列对比 的副本」已有，则存为「多列对比 的副本 2」，再存为「… 3」）；加后缀后超 40 字时截掉原名末尾，保证后缀完整。

### 1.3 成功 / 失败

| 结果 | 反馈 | 后续 |
|---|---|---|
| 成功 | toast「已保存到我的模板」+ 次链「去模板库看看」 | **仍留在当前 P2**；不强制跳走（UX-SAVE-b） |
| 失败 | 「保存失败，请重试」+ 重试 | 弹层可保留已填名称 |
| 存储满/配额（若有） | 「我的模板已满，请先删除不用的」 | 链到 P1 我的模板 |

保存内容 = **当前实例 JSON**（文案槽 + 已落区块 + 主题等），骨架与槽位规则不变；**不**解锁增删行列或画布。  
策略：**只新增、不覆盖**已有「我的」原件（UX-SAVE-c）；要改已有库内模板 = 选用 → 改 → 再另存一条。

### 1.4 与「导出」区分

| | 另存为模板 | 导出 |
|---|---|---|
| 目的 | 下次再编辑 | 拿走 HTML/PNG |
| 结果 | 进 P1「我的模板」 | 剪贴板 / 文件 |
| 是否改库 | 是 | 否 |

## 2. P1 · 我的模板 vs 系统预设

### 2.1 分区

```
[ Chip：全部 | 多列对比 | 单主体明细 | … ]
[ 段标题：我的模板 ]     ← 有数据才显示；空则保留段标题并显示一行「还没有自己的模板。在编辑台改好后点「另存为模板」」（唯一空态文案，Q-013）
[ 卡片… ]
[ 段标题：系统模板 ]
[ 卡片… ]
```

| 分区 | 来源 | 卡片角标 | 可删 |
|---|---|---|---|
| **我的模板** | 用户另存 | 「我的」 | ✓ 卡片菜单「删除」（二次确认） |
| **系统模板** | 产品预置 | 无 / 「官方」 | ✗ |

选用流程与系统模板相同：「使用此模板」→ 克隆新实例进 P2（**不直接改库内原件**）。

### 2.2 空态 / 管理

| 状态 | 文案 |
|---|---|
| 我的为空 | 「还没有自己的模板。在编辑台改好后点「另存为模板」」 |
| 删除确认 | 「删除后不可恢复，确定删除？」· 删除 / 取消 |
| 筛选 | Chip 同时滤两区；某区无结果则该段显示「本类暂无」 |

### 2.3 禁止暗示

- 不出现「从空白画布新建模板」
- 「新建」若需要：仅 = 从系统模板选用后再另存（无第二入口造画布）

## 3. 已锁（体验 · SAVE-default）

| ID | 项 | 结论 |
|---|---|---|
| UX-SAVE-a | 我的模板重名 | **允许**；弱提示可改名/自动加后缀；列表靠名称+时间区分 |
| UX-SAVE-b | 另存成功是否跳 P1 | **不跳**；toast + 可选「去模板库看看」 |
| UX-SAVE-c | 覆盖已有「我的」 | **本期不做覆盖**；只新增；编辑已有走「选用→改→再另存」 |
| UX-SAVE-d | 存储 | **本机存**（对齐架构 §6.1）；体验文案：「保存在本机，刷新后仍可用」 |
