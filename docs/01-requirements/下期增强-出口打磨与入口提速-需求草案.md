## 1. OUT-5 边界改写（下期生效）

| 编号 | 下期口径 | 说明 |
|------|------|------|
| OUT-5a | **剪贴板粘贴填槽：要做**（FR-N01～N04） | 只接收从 Excel / WPS / 表格软件复制出来的单元格文本，只往已有的可写槽位里填，**不改表格结构** |
| OUT-5b | **文件导入（.xlsx/.csv 上传）、网页抓表：仍不做** | 后置 |
| OUT-5c | **Excel 导出：仍不做** | 后置 |

> 改写理由：竞品几乎都能粘贴（TableConvert、MakeCharts、Tabella），手填是我们最大的短板；而文件导入会牵出格式兼容和结构识别，范围膨胀太大。

## 2. 功能需求（FR）

| 编号 | 所属模块 | 方向 | 优先级 | 描述 | 验收判据（可判定） |
|------|------|------|------|------|------|
| FR-N01 | 编辑台-数据入口 | ② | P0 | 选中一个可写槽位作为起点，粘贴从表格软件复制的多行多列内容，按位置从起点往右往下填 | 从 Excel 复制 3 行×4 列粘贴到起点，对应 12 个槽位全部填上，顺序与原表一致 |
| FR-N02 | 编辑台-数据入口 | ② | P0 | 写入前先**预览落位**（高亮将被覆盖的槽位），用户确认才写入；取消则什么都不变 | 粘贴后出现预览高亮和「确认/取消」；点取消后预览和数据都与粘贴前一致 |
| FR-N03 | 编辑台-数据入口 | ② | P0 | 粘贴块**超出可写范围**（行或列多出来）时**整块拒收**，并说明超出了几行几列；**不截断、不自动扩表** | 4 列内容粘到只剩 3 列可写的位置：无任何槽位被改，提示里写明「多出 1 列」 |
| FR-N04 | 编辑台-数据入口 | ② | P0 | 一次粘贴算**一次操作**：要么全部写进去，要么一个都不写；撤销一步回到粘贴前 | 写入成功后点一次撤销，12 个槽位全部恢复；任何失败都不会只写进一部分 |
| FR-N05 | 渲染-语义单元格 | ① | P0 | 对比类模板支持三种状态符号：✓ 支持、✗ 不支持、◐ 部分支持；样式跟随主题 | 切换 T-A/B/C 三套主题，符号颜色随主题变化；界面上没有自定义符号或颜色的入口 |
| FR-N06 | 渲染-语义单元格 | ① | P1 | 数值槽支持数字、百分比、货币三种显示格式（由模板声明） | 同一个数值在三种格式下分别显示正确（例：`0.25` 显示为 `25%`） |
| FR-N07 | 渲染-语义单元格 | ① | P1 | 对比模板可以把一列标为「推荐」，用主题强调色加角标；**最多一列** | 标记第二列时，前一列的推荐标记自动取消；导出的 HTML 和 PNG 都能看到角标 |
| FR-N08 | 导出-PNG | ① | P0 | PNG 可选 1x / 2x / 3x 倍率（默认 2x）；可选透明背景 | 2x 导出图片宽度为预览宽度的 2 倍（±2px）；勾选透明后，表格以外区域是透明的 |
| FR-N09 | 导出-HTML | ① | P0 | 复制出来的 HTML 带表头、表体、表标题等语义结构，样式写在标签里，粘到没有样式表的页面也能看 | 粘到空白 HTML 和一个常见富文本编辑器 [? 具体哪个待定]，主题色、合并、符号都还在 |
| FR-N10 | 导出-HTML | ① | P1 | 复制出来的 HTML 在手机窄屏（≤375px 宽）上不撑破页面 | 在 375px 宽的页面里打开，表格不会让整页出现横向溢出 |
| FR-N11 | 模板库 | ② | P1 | 模板品类新增**价目表**、**矩阵表**各至少 1 个（本期 FR-01 的后置项提前） | 模板库能看到这两类，且都能走完粘贴填槽和导出 |
| FR-N12 | 导出-Markdown | ① | P2 | 可选导出 Markdown 表格；有合并格时提示「Markdown 不支持合并，已拆开展示」 | [待确认是否纳入] |

## 3. 下期本次不做

1. 粘贴时自动加行加列、扩表（会踩到 Mid，见 OUT-10）
2. 上传 .xlsx/.csv 文件导入、网页抓表、图片识别成表
3. Excel 导出
4. AI 文字生成表（方向③，后置另立项，需要另写 ADR）
5. 自定义符号、自定义颜色或 hex、品牌色
6. 条件着色、热力图、迷你条形图
7. 分享链接、在线嵌入、账号
8. 任何 Mid / Heavy 编辑能力
