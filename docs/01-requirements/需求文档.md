## 1. 背景与目标

**谁**：**验收主角 = 自用内容作者**（行业不限：保险/教培/电商价目/测评/课表行程等均可）；运营/运营设计可走同路径但不单独验收集；先自用网页出表，二期可嵌入站点（嵌入本期仅概念预留）。  
**痛点**：Excel/Word 难贴网且难看；手写 HTML 合并/多级头累；设计站出图难维护结构化 HTML；电子表工具又太重。  
**做什么**：从**多类型模板库**（系统预设 + **我的模板**）选底稿 →（可选）拖入表内区块填槽 → 填字换皮 → **另存为模板**以便复用 → 复制 HTML / 导出 PNG。核心闭环：**可自定义 → 另存模板 → 复用**；不锁死单一行业。  
**成功标准（首验）**：

1. 用首发 **对比** 或 **明细** 模板之一填完文案并换主题后，复制出的 HTML 在空白页观感接近样例（可换色、斑马纹、强调可读）；  
2. 至少 1 张含多级表头或 rowspan/colspan 的模板可轻编辑后导出 PNG；  
3. 不出现公式栏/随意增删行列等「弱 Excel」能力入口；  
4. 可从组件库拖入 ≥2 类表内区块，落成后仍属同一张表模板，非自由画布；  
5. 模板库信息架构支持**多类型分类**（首发上架对比+明细；矩阵/价目等分类位预留，本期可不展示空类）；
6. 编辑台可将当前实例 **另存为模板**，在「我的模板」再选用并得到等价结构（允许文案/主题已写入）；
7. **Fill 路径**：在模板允许合并区内完成「选区→合并→改字→拆分（非 locked）→对齐→强调→另存」；非允许区仅禁操作提示；无增删行列/列宽拖/筛排/填充柄入口。

> 场景与竞品、画布评估见 `research/场景扩展-竞品与画布评估-2026-10-20.md`。

### 3.2 功能需求

| FR | 模块 | 优先级 | 描述 | 验收判据 |
|----|------|--------|------|----------|
| FR-01 | 模板库 | P0 | 模板库含 **系统预设**（首发 **C-compare + C-detail** 各 ≥1）与 **我的模板** 分区/筛选；支持类型字段；矩阵·价目后置可扩 | 可见系统两类骨架 +「我的模板」入口（可为空态）；点任一可进编辑台；数据含 type 与来源（system/user） |
| FR-02 | 编辑台-填空 | P0 | 按模板槽位编辑文案/数值，预览同步 | 改槽位后预览对应单元格更新；空槽有占位提示 |
| FR-03 | 编辑台-轻编辑（Fill） | P0 | 支持：① 改单元格文案；② 切换主题（**三套** T-A/T-B/T-C，含斑马纹/强调色；无自定义 hex）；③ **允许区**多选相邻格→合并（工具条/属性入口 + 合并后微反馈）；④ **拆分**已合并格（用户自并 / 非 `locked` 预设；locked 仅禁操作提示）；⑤ **对齐**左/中/右；⑥ **强调**入口可见，只有**红字 / 加粗 / 底色**三项，不做角标（Q-004）；⑦ 区块样式 2～3 档微调（与 FR-08/09 并存） | 可切满三套且默认 T-A；允许区完成选区→合并→改字→拆分→对齐→强调全路径；非允许区仅禁操作提示、无任意合并入口；无增删行列/列宽拖/筛排/填充柄入口；无 Excel 拖角合并 |
| FR-04 | 版式渲染 | P0 | 渲染多级表头、rowspan/colspan、分区色条、宽表横滚+首列钉（按模板启用） | 首批模板中至少 1 个覆盖「多级头或合并」；预览与导出 HTML 结构一致 |
| FR-05 | 导出-HTML | P0 | 复制当前表为 HTML（含主题样式或可内联的必要样式） | 粘贴到空白 HTML 打开后，主题色/强调/合并仍可读；无依赖本地未提供的私有资源 |
| FR-06 | 导出-PNG | P0 | 导出当前预览为 PNG | 分辨率可供方案书使用；内容与预览一致（允许 1～2px 抗锯齿差） |
| FR-07 | 交付分层 | P1 | 在线工具壳与表格渲染核分离，预留嵌入 | 代码/文档可指出「渲染核」边界；本期可不提供对外 npm/SDK，但禁止把模板逻辑写死在不可复用的单页 DOM 脚本里（假设，架构 ADR 细化）。**本期验收方式**（Q-016）：纳入本期验收，但属于**评审项**，不做界面功能测试、不交陌生人测试执行；由架构师按设计文档中的渲染核边界章节列检查点，主控在代码评审时逐条核对并记录结论。与 U-4「嵌入不进本期功能验收」不冲突：U-4 管对外嵌入功能，FR-07 只管内部分层 |
| FR-08 | 表内区块组件 | **P0（本期）** | 预设区块组件库；从左侧拖入**模板内槽位**（非整页自由坐标）；落成写入模板 JSON，由渲染核画出 | 分区色条、分组标题行 2 类区块可拖入并填字；强调注脚、左栏标签在区块库中可见但置灰，不能拖入（P-4，二期开放）；拖入后仍是一张表；无表外自由摆放；验收对照 `03-ux` 拖拽对象清单 |
| FR-09 | 编辑台-区块管理 | P0 | 已落入区块可**选中、改文案、删除**；同槽位再拖入**替换原区块**（色条与分组标题行同一位置只能放一个，后拖入的替换原有的） | 删除后预览与 JSON 同步无残留；选中有可见态；无「撤销删除」亦可过（撤销见 FR-11） |
| FR-10 | 编辑台-离开保护与刷新恢复 | P1 | 有未保存改动时离开编辑台（回模板库/关页）须确认；刷新或重开后自动恢复最近一次编辑（P-1 已确认） | 离开确认文案为「离开后，没另存为模板的改动只保留最近一份，可下次打开时继续」，关页走浏览器自带确认；无改动不弹。重开后直接进编辑台并恢复，顶部提示「已恢复上次的编辑」，并给出「不恢复，重新选模板」，点击后须二次确认；恢复失败时按模板初始状态打开，顶部提示「上次的编辑没能恢复，已按模板重新打开」，不弹窗；恢复后撤销按钮为灰（撤销记录不跨刷新）。文案以 `03-ux/页面流-模板库编辑台导出.md` §3 P2「刷新恢复」为准。**「有未保存改动」的判定**（Q-006）：上次另存为模板之后又有改动，就算有未保存改动；导出不算保存。关页、刷新时只用浏览器自带的离开确认，不要求显示自定义文案。在模板库换一张模板时，一律二次确认「会替换当前的表」，不走撤销 |
| FR-11 | 编辑台-撤销 | P1 | 至少支持最近一次「改槽位文案 / 换主题 / 拖入或删除区块 / **合并 / 拆分 / 对齐 / 强调**」的撤销（**只撤一步，不做重做**，Q-005） | 点撤销后预览回到撤销前（含合并、拆分、对齐、强调）；无云端历史；连续做两次操作后只能撤回最后一次；撤销一次后撤销按钮变灰，直到下一次操作才恢复可用 |
| FR-12 | 导出反馈 | P0 | 复制 HTML / 下 PNG 有成功与失败反馈；失败可重试；过程防连点 | 成功有 toast 或等价；失败文案可读；PNG 进行中按钮禁用 |

## 8. 操作体验细则（本期可判定 · 文档深化）

> 细节交互以 `03-ux/` 为准；本节写**产品必须满足**的体验底线，供验收对照。

| 场景 | 期望 | 验收要点 |
|------|------|----------|
| 空槽 | 未填槽显示占位文案（如「点击填写」），不显示空白无提示 | 占位可见；填写后占位消失 |
| 点选编辑 | 点预览单元格或右侧列表均可编辑对应槽 | 预览与右侧同步；焦点不丢预览滚动位置（允许小偏移） |
| 主题切换 | 切换即时刷新预览；斑马纹/强调随主题 token | 切换后预览立即变化，无整页 loading。「<1s」只作参考记录，**不作验收门槛**，超时不判失败（Q-019） |
| 拖入未命中 | 回弹 + 短提示，不落块 | 无残留半透明幽灵块 |
| 同槽再拖入 | **当前假设：替换**已有区块（与 UX 体验深化一致；可改「拒绝」） | 槽内仅保留一块；JSON 无双块叠压 |
| 删除区块 | 属性面板或选中后删除 | 见 FR-09 |
| 有限合并（Fill） | 仅模板允许区（如 `mergeAllow` / `allowedMerges`，名可调）内：多选→合并→边框微闪+toast；入口为工具条/属性，**无** Excel 拖角 | 允许区可走通合并；非允许区仅禁操作提示 |
| 拆分（Fill） | 选中已合并格→拆分；`locked` 预设不可拆 | locked 点拆分仅提示；用户自并可拆回 |
| 对齐（Fill） | 选中格/合并格可切左中右（类型建议可约束默认） | 切换后预览与导出一致 |
| 强调入口（Fill） | 工具条/属性可见强调（红字 / 加粗 / 底色，不做角标）；与主题 token 并存 | 入口可发现；表头行、左栏项名、非槽只读格、区块内不能强调，三个按钮置灰并提示「此处由模板固定，不能强调」（Q-004，对齐交互体验深化 §2.3.4） |
| 区块样式微调（Fill） | 已落区块提供 2～3 档样式（如色条深浅、分组标题行字重） | 档位切换可见；仍属表内区块非画布 |
| 宽表 | 启用钉列的模板：横滚时首列（或模板规定列）保持可见 | 滚动后标签列仍可读 |
| 离开 | 见 FR-10 | — |
| 导出 | 见 FR-12；Excel **无入口** | P3 或抽屉等价 |

**本地持久化**：① 当前编辑实例：可用内存 / `localStorage`；刷新/重开后**自动恢复最近一次编辑**（P-1 已拍板）。② **我的模板**（FR-13）：**已拍板 U-8** 落本机浏览器持久化；**不做**账号云存（OUT-3）。

## 9. 边界与非功能假设

| 项 | 当前假设 | 备注 |
|----|----------|------|
| 表规模 | 首批模板 ≤ **20 行 × 12 列**（含合并视觉格）；超出不承诺流畅 | 宽表评测若入选，列可到 12，行仍 ≤20 |
| 终端 | **桌面浏览器优先**（Chromium / Safari 近两版）；移动端可看不可完整编辑 | 不做移动端专项交互 |
| 无障碍 | 不设完整 WCAG 目标；控件需有可见 label；拖拽须有「点击添加」等价入口（防纯拖不可达） | UX 补点击添加 |
| 性能 | 主题切换与单次拖入后预览刷新体感「即时」；PNG 导出允许数秒 | 架构写入约束 |
| 安全 | 槽位文案按文本处理；导出 HTML 需转义，防脚本注入 | 开发契约 |
| 国际化 | 本期仅中文 UI | — |
