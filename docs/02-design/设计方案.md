## 1. 系统形态

| 项 | 结论 |
|----|------|
| 交付 | **在线工具为主**（SPA）；**嵌入预留**（本期不交付 SDK） |
| 分层 | **App Shell（壳）** + **Render Core（核）** |
| 产品组合 | **B 模板首发** + **A 轻编辑**（填槽 / 换肤 / 有限合并） |
| 非目标 | 非 Excel：无随意增删行列、公式、完整电子表、自由画布拼表 |

```
模板库 → 编辑台（壳：组件库 DnD + 属性；核：VTable 预览）→ 导出（HTML / PNG）
```

**U-6=A（一句）**：壳层「表内区块槽位」DnD → 写入模板 JSON；自由画布后置；**VTable 只渲染，不当通用画布**。

## 2. 模块清单

| 模块 | 职责 | 依赖 | 本期 |
|------|------|------|------|
| **shell-app** | 路由/页面壳；模板库 UI；编辑台三栏布局；导出入口编排 | render-core、template-store | 做 |
| **template-store** | 加载/校验模板 JSON；维护当前实例（slots/blocks/theme） | 无（纯数据） | 做 |
| **slot-dnd** | 左组件库拖拽；槽位 hit-test；未命中回弹；落成写 `blocks[]` | template-store | 做（FR-08） |
| **property-panel** | 槽位文案、主题/斑马纹、强调、有限合并、选中区块属性 | template-store | 做 |
| **render-core** | `mount`；JSON→VTable option；主题 token 映射；预览刷新 | `@visactor/vtable` | 做 |
| **export-html** | 由当前实例生成可粘贴 HTML（含必要内联样式） | template-store / render-core | 做 |
| **export-png** | 预览区域出图为 PNG | render-core | 做 |
| **embed-api** | 对外 `mount(el, options)` 文档化预留 | render-core | 预留（不交付 SDK） |

依赖方向：**壳 → store → 核**；禁止核反向依赖壳 UI。

## 3. 数据模型

### 3.1 模板实例（运行时）

| 字段 | 含义 |
|------|------|
| `templateId` | 底稿 ID |
| `themeId` / `themeTokens` | 主题与 token（主色、斑马纹、强调色等） |
| `slots` | 文案/数值槽（含单元格键） |
| `blocks[]` | 已落入的表内区块（`sectionBar` / `groupHeader` / `emphFooter` / `leftTag` …） |
| `layout` | 钉列、允许的 merges 等结构约束 |

语义锁定；字段名实现可微调。完整示例见 ADR §6。

**字段级必填/可选、blockSlots、校验规则**：详见 [开发约定-壳核与导出.md](开发约定-壳核与导出.md) §2（G-AR-01）。

### 3.2 主题 token（最小集）

| token | 用途 |
|-------|------|
| `primary` | 表头/分区主色 |
| `zebra` | 斑马纹开关或色 |
| `emphasis` | 强调红字/底色 |
| （可扩展） | 边框、背景、标签色——实现期对齐 UX 主题套数（U-2） |

### 3.3 导出产物

- **HTML**：粘贴即用；主题/合并/区块可读；无未提供私有资源依赖  
- **PNG**：与预览一致（允许 1～2px 抗锯齿差）  
- Excel：**后置**，界面无入口

## 4. 对外接口骨架（嵌入后置）

概念级（非实现代码）：

```ts
mount(el: HTMLElement, options?: CoreOptions): CoreHandle

interface CoreHandle {
  loadTemplate(json: TemplateJSON): void
  applyTheme(themeId: string | ThemeTokens): void
  setSlot(slotId: string, value: string | number): void
  addBlock(block: BlockDesc): void
  removeBlock(blockId: string): void
  exportHtml(): Promise<string>
  exportPng(): Promise<Blob>
  destroy(): void
}
```

- 在线工具壳调用上述 API；**禁止**把模板逻辑写死在不可复用单页脚本（FR-07）。  
- 嵌入 props/事件细节属 U-4，二期再定；本期保持可映射。
- **函数签名级 + 壳事件对照表**：见开发约定 §3（G-AR-04）。

## 6. U-6=A 与主核边界

- **壳**：DnD + 槽位校验 + 写 JSON。  
- **核（VTable）**：只根据 JSON 渲染。  
- **后置**：自由画布、表外图文、单元格 Excel 式拖合并。  
- 选型对比与放弃理由见 **ADR-001**（VTable 选用；FortuneSheet/Univer 后置；TanStack/Tabulator/AG Grid 不作主核）。

## 7. 失败处理

| 场景 | 原则 |
|------|------|
| 模板损坏 | 预览错误态 + 重试/回库；侧栏保留 |
| 主题缺失 | 回退默认主题 + toast |
| 槽位未命中 / 未知 slot | 拒绝写入；回弹提示；不落临时 DOM |
| 未实现 block 类型 | 可观测警告或占位条（实现二选一） |
| 导出失败 | 明确错误 + 可重试；PNG 过程防连点 |
| 渲染异常 | 捕获；保留 JSON；允许重新渲染 |

**错误码 / 可观测性**：见开发约定 §4（G-AR-03）。**导出内联与尺寸**：见开发约定 §5（G-AR-02）。**规模硬约束**：见开发约定 §6（G-AR-05）。
