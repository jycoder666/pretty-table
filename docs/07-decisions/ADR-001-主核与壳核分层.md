## 1. 背景

pretty-table 要做「保险/对比类**精美展示表**」：选模板 → 填槽换皮 →（可选）拖入表内区块 → 复制 HTML / 导出 PNG。  
产品已锁：**B 模板首发 + A 轻编辑**；**在线工具为主、预留嵌入**；**U-6=A 表内槽位拖入**（自由画布后置）。  
非 Excel：无随意增删行列、无公式、无完整电子表体验（OUT-1～4、OUT-8/9）。  
需选定**表格渲染主核**，并划清 **app shell（壳）** 与 **render core（核）** 边界，避免 DnD 滑成自由画布或把重编辑器当主路径。

---

## 2. 决策（摘要）

| 项 | 结论 |
|----|------|
| 系统形态 | 在线 SPA 壳 + 可复用渲染核；嵌入仅预留 `mount`，本期不交付 SDK |
| 产品组合 | **B 模板 + A 轻编辑**（填槽 / 换肤 / 有限合并）；**非 Excel** |
| **主核** | **VisActor VTable（MIT）** |
| DnD（U-6=A） | **壳层**「表内区块槽位」拖入 → 写模板 JSON；**禁止**自由画布；**DnD 不进 VTable 内部当通用画布** |
| 导出 | HTML + PNG；Excel 后置 |
| 自研引擎 | **不做**（复用优先） |

一句话：**VTable 只渲染；壳管模板库/主题/槽位 DnD/导出；槽位进 JSON，画布后置。**

---

## 3. 系统形态与壳/核分层

```
┌─────────────────────────────────────────────┐
│ App Shell（在线工具）                        │
│  模板库 · 左组件库 DnD · 右属性 · 导出编排   │
│  写入 / 读取 Template JSON                   │
└──────────────────┬──────────────────────────┘
                   │ loadTemplate / applyTheme /
                   │ setSlot / export*
┌──────────────────▼──────────────────────────┐
│ Render Core（可嵌入预留）                    │
│  VTable 挂载 · 布局/合并/多级头 · theme token│
│  把 JSON → 可见表（预览 = 导出同源数据）     │
└─────────────────────────────────────────────┘
```

| 层 | 负责 | 不负责 |
|----|------|--------|
| **壳** | 模板库导航；主题切换 UI；**槽位组件库 DnD**（落点校验、回弹提示）；属性面板；导出按钮编排；实例状态 | 自绘单元格像素；在 VTable 内做自由坐标画布 |
| **核** | 表格渲染；多级头 / rowspan·colspan；分区色条等**已写入 JSON 的区块**；主题 token → VTable theme；钉列/横滚（按模板） | 模板市场；拖拽手势状态机；剪贴板权限 UX |

嵌入预留：宿主只挂核（`mount(el, options)`）；本期壳做成完整在线工具即可（FR-07 P1）。

## 4. 主核选型对比（外搜 · GitHub API 核实）

检索时间：**2026-10-20**（Asia/Shanghai）。星标来自 GitHub API `stargazers_count`；许可以仓库 `license.spdx_id` / LICENSE 文件为准。

### 4.1 对比表

| 候选 | 星标 | 许可 | 定位 | 与「模板展示+轻编辑」 | 维护活跃（pushed_at） | 本期处置 |
|------|------|------|------|----------------------|----------------------|----------|
| **VTable** [外](https://github.com/VisActor/VTable) | **3679** | **MIT** | Canvas 高性能表 / 主题与自定义单元格强 | **高**：多级头、主题、合并、展示型版式契合 | 2026-10-19 · 活跃 | **选用主核** |
| FortuneSheet [外](https://github.com/ruilisi/fortune-sheet) | **3738** | **MIT** | 类 Excel / Google Sheets 电子表 | **低**：重编辑默认路径，易违反 OUT | 2025-12-15 · 偏缓 | **后置**（若要重编辑再议） |
| Univer OSS [外](https://github.com/dream-num/univer) | **22680** | **Apache-2.0** | Office SDK（表/文/幻灯）；另有 Pro 商业层 | **低（本期）**：能力过重；产品心智=电子表 | 2026-10-19 · 很活跃 | **后置/对照**；勿作本期主路径 |
| TanStack Table [外](https://github.com/TanStack/table) | **28503** | **MIT** | **无头**表逻辑（排序筛选分页） | **不适合作主核**：无开箱精美渲染/合并画布 | 2026-10-12 · 活跃 | **不用作主核**；若自研 DOM 表可作逻辑备选（本期不取） |
| Tabulator [外](https://github.com/tabulator-tables/tabulator) | **7788** | **MIT** | 交互数据网格 | **弱**：业务网格强，保险对比「精美版式」弱 | 2026-10-18 · 活跃 | **放弃作主核**（需求 OUT-6） |
| AG Grid Community [外](https://github.com/ag-grid/ag-grid) | **15645** | 仓标 **Other**；Community 通常 MIT、Enterprise 商业（[?](https://www.ag-grid.com/license-pricing/) 以官网分层为准） | 企业数据网格 | **弱**：网格/筛选强，非模板展示表；许可边界需额外审 | 2026-10-20 · 活跃 | **放弃作主核**（OUT-6）；且许可需单独审计 |

### 4.2 选用：VTable

- **契合**：展示型表格、主题换皮、自定义单元格/图标、多级头与合并，贴合保险对比/保障明细样例。  
- **许可**：MIT，满足「仅 MIT/Apache-2.0」（OUT-7）。  
- **活跃**：近期持续 release（npm `@visactor/vtable`；文档 [visactor.io/vtable](https://visactor.io/vtable)）。  
- **分层友好**：核内只吃 option/records/theme；壳用 JSON 驱动，不必 fork 引擎。

### 4.3 放弃 / 后置理由

| 方案 | 理由 |
|------|------|
| FortuneSheet | 默认「可编辑电子表」心智；本期要藏增删行列/公式；用作主核易做成弱 Excel → **后置** |
| Univer OSS | 体量大、Office 全家桶；本期只要模板展示+轻编辑；Pro 边界需持续警惕 → **后置对照** |
| TanStack Table | 无 UI：自研渲染成本≈自研引擎，违反复用优先 |
| Tabulator / AG Grid | 数据网格定位；精美分区色条/保险对比版式非长项；需求已 OUT |
| 从零自研 Canvas/DOM 表引擎 | 合并、钉列、主题、导出一致性成本高；无收益 → **禁止** |

## 5. U-6=A 边界（DnD）

对齐 UX §5 / FR-08：

| 允许 | 禁止 |
|------|------|
| 左组件库拖入：**分区色条 / 分组标题行 / 强调注脚 / 左栏标签块**（首发可先 2 类） | 自由画布、任意 xy、表外卡片/图文混排 |
| 落点 = 模板预留**槽位**（高亮）；未命中 → 回弹 + 短提示 | 拖到预览空白任意落点 |
| 落成写入模板 JSON（`blocks[]`），核只渲染 | DnD 状态机塞进 VTable 插件当通用画布 |
| 拖入后仍是**一张表**；导出与预览同源 | 单元格拖合并/拖排序当 Excel；随意增删行列 |

**架构硬规则**：壳完成 hit-test → `setSlot` / `addBlock` → 核 `updateOption`；**不**把 VTable 当低代码画布运行时。

## 6. 数据模型骨架（概念）

```json
{
  "templateId": "insurance-compare-v1",
  "themeId": "blue-white",
  "themeTokens": {
    "primary": "#1a5fb4",
    "zebra": true,
    "emphasis": "#c01c28"
  },
  "slots": {
    "title": "产品保障对比",
    "cells": { "r2c3": "重疾赔付" }
  },
  "blocks": [
    { "id": "b1", "type": "sectionBar", "slotId": "row-gap-3", "props": { "label": "基础保障" } },
    { "id": "b2", "type": "groupHeader", "slotId": "group-1", "props": { "text": "身故责任" } },
    { "id": "b3", "type": "emphFooter", "slotId": "footer-1", "props": { "text": "以条款为准" } },
    { "id": "b4", "type": "leftTag", "slotId": "left-r5", "props": { "text": "推荐" } }
  ],
  "layout": {
    "frozenColCount": 1,
    "merges": [{ "start": [0,0], "end": [0,2] }]
  }
}
```

**导出产物**：

| 产物 | 约定 |
|------|------|
| HTML | 可粘贴片段；主题色/合并/区块可读；不依赖本地未提供私有资源 |
| PNG | 与预览一致（允许 1～2px 抗锯齿差） |

字段名实现期可微调；**语义**（theme / slots / blocks / layout）本期锁定。

## 7. 对外接口骨架（概念 · 非实现）

```ts
// Render Core
mount(el: HTMLElement, options?: CoreOptions): CoreHandle

interface CoreHandle {
  loadTemplate(json: TemplateJSON): void
  applyTheme(themeId: string | ThemeTokens): void
  setSlot(slotId: string, value: string | number): void
  addBlock(block: BlockDesc): void      // 壳 DnD 落成后调用
  removeBlock(blockId: string): void
  exportHtml(): Promise<string>
  exportPng(): Promise<Blob>
  destroy(): void
}
```

- 壳可再包一层 UI Store；**禁止**把模板逻辑写死在不可复用的单页 DOM 脚本（FR-07）。  
- 嵌入二期再定 props/事件细节（U-4）；本期接口保持可映射即可。

## 8. 失败处理原则

| 场景 | 原则 |
|------|------|
| 模板 JSON 损坏 / 缺必填 | 核不抛崩整页；预览区错误态 +「重试/回模板库」；壳保留侧栏 |
| 主题 id 缺失 | 回退默认主题（假设蓝白）；toast「主题不存在，已用默认」 |
| 槽位溢出 / 未知 slotId | `setSlot`/`addBlock` 拒绝写入；壳提示「请放到表内虚线槽位」；不落临时 DOM |
| 区块类型未实现 | 忽略该 block 并记警告；或显示占位条「组件暂不可用」——二选一实现期定，须可观测 |
| 导出 HTML 失败 | 明确错误 + 可重试；不静默 |
| 导出 PNG 失败 | 禁用重复点击至结束；错误文案 + 重试；进度态见 UX P3 |
| VTable 渲染异常 | 捕获后预览错误态；保留 JSON，允许「重新渲染」 |

---

## 9. 复用优先

- 多级头、合并、钉列、主题、大数据渲染已有成熟引擎；自研无差异化收益。  
- 产品差异在**模板 JSON + 壳层体验 + 导出观感**，不在栅格算法。  
- 许可约束下 VTable 满足 MIT；与「精美展示」叙事一致。

---

## 10. 后果

**好处**：主路径清晰；DnD 不污染核；嵌入可只挂核；避开电子表心智。  
**代价**：须维护「模板 JSON ↔ VTable option」适配层；复杂版式依赖自定义单元格/行定义。  
**后续**：设计方案骨架已落 `02-design/设计方案.md`；主控门禁后派实现；U-1 首批模板、U-2 主题套数仍待确认，不挡本 ADR。

## 12. 一句话
