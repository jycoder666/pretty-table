- 环境：桌面 Chrome 最新版，Windows，缩放 100%，窗口 1440×900（另注明者除外）；每条 TC 开始前清空本站 localStorage/IndexedDB，除非前置写明保留。

- MVP 用例（一）按本期验收；增强期用例（二）只在增强期版本执行（E-7），本期验收不含。
