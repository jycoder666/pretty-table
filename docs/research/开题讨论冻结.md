## 讨论倾向（待写进需求 / 待确认项仍标「待确认」）

| 项 | 内容 |
|----|------|
| MVP | 保险/对比类模板填空换皮 + 轻编辑 + 表内区块槽位拖入 |
| 轻编辑粒度 | 改单元格文案、换主题/斑马纹/强调色、有限合并（模板已开区可调） |
| 不做（本期） | 随意增删行列、公式、协作、完整电子表、重编辑、自由画布拼表 |
| 导出草案 | 复制 HTML + 导出 PNG；Excel 后置 |
| 主核倾向 | VTable（MIT）扛多级头/主题/展示；FortuneSheet / Univer 重编辑后置 |
| 放弃作主核 | AG Grid / Tabulator（网格强、保险对比版式弱）；从零画表引擎；非 MIT/Apache 路径 |

## 版式能力（交互抽样例，待落 `03-ux/`）

- 结构：多级表头、左/顶栏色块、rowspan/colspan、分区色条、宽表横滚+首列钉
- 视觉：主题可换、斑马纹、外框、单元格强调、数字右齐等
- 交互流草案：模板库 → 编辑台（左预览右属性 / 可含组件托盘）→ 导出
