## 4. 可选方向（文档深化策略 · 不催实施）

| 方向 | 内容 | 取舍 |
|------|------|------|
| **A · 需求体验优先（本期采用）** | 先补需求操作/边界 FR + 开放项假设；同步抛 UX/架构缺口表 | 最快对齐「可验收」；开发细节并行 |
| B · 开发契约优先 | 先写死 JSON schema / 导出契约 | 体验文案可能再改契约，返工风险 |
| C · 先拍 U-1 模板再写细 | 先定模板名单再展开结构 | 用户未要求拍板；违反「不催开干」 |

**放弃 B/C 理由**：用户要「细节+体验」且暂不开码；A 不阻塞实现、不逼模板拍板。
