# 许可证 · 传递依赖处置方案（OUT-7 释义）

> 作者：架构师 ｜ 2026-10-20 ｜ 状态：**已拍板：用户 2026-10-20 选 A**（落地见实施计划 T35；需求 OUT-7 由 PM 回写）
> 依据：`research/PoC-结果-2026-10-20.md` §6；需求 OUT-7「依赖仅 MIT / Apache-2.0」；`02-design/增强期-设计增量.md` §6

## 1. 现状（PoC 实测，`npm ls --omit=dev --all` 125 个运行时包）

| 许可 | 个数 | 主要来源 | 性质 |
|------|------|----------|------|
| MIT | 93 | 大部分 | 宽松 |
| BSD-3-Clause / BSD-2-Clause | 14 / 3 | VTable → vdataset → d3-geo、d3-array、shapefile 等 | 宽松（保留版权声明即可） |
| ISC | 9 | 同上 | 宽松（与 MIT 等价） |
| Apache-2.0 | 2 | idb-keyval 等 | 宽松 |
| MPL-2.0 | 2 | VTable → vrender-kits → `@resvg/resvg-js`（Node 原生 SVG 渲染） | **弱著佐权**：只约束「修改过的 MPL 文件本身」须开源，不传染到调用方代码 |
| Unlicense / 0BSD | 1 / 1 | text-encoding、tslib | 等同公有领域 |

关键事实：PoC 查 `vite build` 产物，`@resvg/resvg-js` 的原生代码**没有进浏览器包**，只留了一句报错字符串。直接依赖全部是 MIT / Apache-2.0。没有 GPL / LGPL / AGPL。

## 2. 方案对比

| 维度 | A 直接依赖严格 + 传递依赖宽松白名单（推荐） | B 只管直接依赖 | C 全链严格 MIT/Apache，换库 |
|------|------|------|------|
| 规则 | 直接依赖仍仅 MIT/Apache-2.0；传递依赖允许 MIT、Apache-2.0、BSD-2/3、ISC、0BSD、Unlicense；MPL-2.0 只在「不进浏览器产物」时允许；GPL/LGPL/AGPL/未声明 一律阻断 | 直接依赖仅 MIT/Apache-2.0，传递依赖不查 | 运行时全部包都必须 MIT/Apache-2.0 |
| 当前是否合规 | 是 | 是 | 否（要动 VTable） |
| 代价 | 加一条自动检查（见 §3），一次配置 | 零 | 换掉 VTable：要推翻已定的 VTable 渲染选型、PoC 重跑；替代库能否做到全链 MIT 未核查 [? 未核实] |
| 风险 | 低：宽松许可只需保留版权声明；MPL 不进产物 | 中：以后升级可能悄悄带进 GPL 类依赖而无人发现 | 实现期大幅延后 |
| 对 OUT-7 | 细化释义，不放宽直接依赖 | 放宽释义 | 维持最严字面 |

**推荐 A**：守住 OUT-7 的本意（不被著佐权许可传染、不惹法律麻烦），不为纯宽松许可返工；同时比 B 多一道自动防线。

放弃 B 的理由：零防护，以后升级 VTable 或加新库时可能带进 GPL 系依赖而无人察觉。
放弃 C 的理由：BSD/ISC 与 MIT 法律效果几乎相同，为它换核心渲染库代价远大于收益。

## 3. 选 A 时怎么落地（实施计划同步）

| 项 | 做法 |
|----|------|
| 检查工具 | 用 pnpm 自带的 `pnpm licenses list --prod --json`（不新增依赖），写一个小脚本 `scripts/check-licenses.mjs` 对照白名单 |
| 白名单 | `MIT, Apache-2.0, BSD-2-Clause, BSD-3-Clause, ISC, 0BSD, Unlicense`；`MPL-2.0` 只放行 `@resvg/resvg-js` 一个包名（例外清单写死，新增例外须架构 + 用户同意） |
| 产物检查 | 同一脚本在 `pnpm build` 后扫描 `dist/`，若出现 resvg 原生代码（`.node` 文件或 wasm）即失败 |
| 何时跑 | `pnpm check:licenses` 进 CI 门禁与主控代码评审；升级依赖必须重跑 |
| 声明 | 构建时生成 `dist/THIRD-PARTY-LICENSES.txt`，保留 BSD/ISC 等要求的版权声明 |
| 需求回写 | 用户选 A 后，由 PM 把 OUT-7 改为本方案的释义 |
