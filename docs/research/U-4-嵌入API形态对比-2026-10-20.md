## 1. 常见做法（外搜）

| 做法 | 要点 | 证据 |
|------|------|------|
| SPA 内挂 SDK | React 宿主 `onReady` 拿 handle，命令式 load/set | [外] [Casual Sheets sdk-usage](https://github.com/CasualOffice/sheets/blob/main/docs/sdk-usage.md) |
| iframe + postMessage | 无 React 依赖；`hostOrigin` 校验；可藏 chrome | [外] [Casual iframe embed](https://casualoffice.org/docs/editor/iframe-embed/) |
| 平台内 Apps SDK | 跑在平台 iframe，API 注入；非白标嵌编辑器 | [外] [Canva Apps](https://www.canva.dev/docs/apps/integrating-canva/) |

**对本期含义**：完整嵌入至少要选「SDK 或 iframe 协议」之一并定 props/事件——工作量属二期；本期只保留**可映射的 CoreHandle 概念**即可对齐业界「先核后壳」路径。
