# pretty-table

网页精美表格工具。给自用内容作者一条短路径：从模板库选底稿，填字、换主题、在允许区内做轻量版式调整，把结果另存成自己的模板，再复制 HTML 或导出 PNG。

行业不限。首发只上架「多列对比」和「单主体明细」两类系统模板，样例文案用通用商务。不做成 Excel，也不做自由画布。

规格文档不进本仓库，只放源码。下面是产品要做的功能。

## 首发功能

| 功能 | 做什么 |
| --- | --- |
| 模板库 | 系统预设至少各一张对比表、明细表；可按类型区分；矩阵、价目分类位预留 |
| 槽位填空 | 按模板预留的文案和数值槽填写，预览同步更新，空槽有占位 |
| 轻编辑 | 改单元格文字；三套主题（蓝白 / 墨青 / 暖灰金），含斑马纹和强调色，不能自定义色值 |
| 合并与拆分 | 只在模板允许区内，多选相邻格后合并；可拆开自己合并的格子和非锁定预设；锁定格只提示不能拆 |
| 对齐与强调 | 左 / 中 / 右对齐；强调只有红字、加粗、底色 |
| 表内区块 | 从左侧拖入分区色条、分组标题行；强调注脚和左栏标签可见但暂不能拖入；同槽再拖入会替换 |
| 区块管理 | 已落入的区块可以选中、改字、删除 |
| 版式 | 多级表头、行列合并、分区色条；需要时宽表横滚并钉住首列 |
| 另存为模板 | 把当前结构、文案、主题和区块存进「我的模板」；只新增不覆盖；重名可存并弱提示；成功后留在编辑台 |
| 我的模板 | 与系统预设分栏；再选开会得到当时存下的结构和内容，可以继续改、再另存成新卡 |
| 复制 HTML | 带上主题和合并，粘到空白页仍可读，不依赖未随包提供的私有资源 |
| 导出 PNG | 与预览一致，可供方案书使用 |
| 导出反馈 | 成功、失败都有提示；失败可重试；导出过程中防连点 |
| 离开与恢复 | 有未另存改动时离开会确认；刷新或重开恢复最近一份编辑 |
| 撤销 | 只撤最近一步：改字、换主题、拖入或删除区块、合并、拆分、对齐、强调 |

编辑台是三栏：左侧组件库，中间预览，右侧属性。数据存在本机浏览器里，没有账号，也没有多人协作。

## 增强期功能

排在首发之后，不进入首发验收。

- 从 Excel / WPS 复制单元格文本，按位置填进已有槽位；写入前预览落位；超出范围、压到合并格或锁定格时整块拒收，不扩表
- 一次粘贴全部成功，或整体回滚；可撤销回粘贴前
- 补价目表、矩阵表系统模板
- 对比表和矩阵表的三态符号：支持 / 不支持 / 部分；颜色跟主题走
- 数值按数字、百分比、货币显示
- 对比表可把一列标成「推荐」，同时最多一列
- PNG 可选 1x / 2x / 3x 和透明背景
- HTML 使用表头、表体、表标题，样式内联，并照顾手机窄屏
- Markdown 导出列为增强期首版不做

## 明确不做

随意增删行列、拖列宽、公式、筛选、排序、冻结、填充柄、Excel 拖角合并、上传 xlsx/csv、网页抓表、图片识别、Excel 导出、自由画布、自定义品牌色、条件着色、分享链接、账号与协作、AI 自动起稿。嵌入站点本期只保留渲染核边界，不交付 SDK。

## 技术形态

在线单页工具。壳负责模板库、拖拽和属性，核用 [VTable](https://github.com/VisActor/VTable) 按模板 JSON 渲染。直接依赖限 MIT / Apache-2.0。脚手架定为 create-vue + Reka UI。
